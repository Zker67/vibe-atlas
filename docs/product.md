## 定位

个人开发者所有 vibe 项目的管理中枢：随手记下每个想法，一条条推进，项目的全貌自然积累出来。

使用场景：一个人在一台电脑上做氛围编程。看到运行结果时，改进点、bug、新需求会一起冒出来，但一次只发一条给 AI。Vibe Atlas 负责三件事：

1. **快速记下**所有想法，不打断手上的工作；
2. 让人**挑出下一条**，复制出去，自己发给 AI；
3. 由人**自己标记进度**；积累下来的记录自动汇总成项目总览。

和 Linear 的区别：不上云、不等待、不同步，没有成员、Cycle、估点和权限，也不内置 AI。

## 使用流程

```text
看到结果 ──▶ 快捷键呼出 ──▶ 连记几条（改进 / bug / 新需求）
                                    │
                                    ▼
                  在待办里排序，挑一条 ──▶ 复制，自己发给 AI
                                    │       （可选：把对话链接存为 deeplink）
                                    ▼
                      手动标为「进行中」 ──▶ 做完后手动打勾「完成」
                                    │
                                    ▼
                  项目总览：各模块进度、完成历史自动汇总
```

## 核心概念

| 概念 | 说明 |
|---|---|
| 项目 | 一个完整项目，比如「规则恐怖」。有名称、图标和项目说明（Markdown），可以绑定一个本地文件夹，也可以不绑。 |
| 模块 | 项目里的一块内容，比如武器系统、人物、关卡、UI。只属于一个项目，可以选一个图标。 |
| 图标 | 项目和模块的图标：内置图标、emoji 或一张本机图片。项目默认「自动」：用绑定的文件夹里项目自己的图标，没找到时用默认的文件夹图标。 |
| 改进点 | 一件具体要做的事。有标题、类型、状态，可以选模块，可选备注（Markdown）和 deeplink。 |
| 子改进点 | 放在另一条改进点下面的改进点，层数不限。上面那条叫父改进点。每一条都有自己的类型、状态和模块。 |
| 前置 | 改进点之间的先后顺序：A 是 B 的前置，表示 B 要等 A 做完，B 是 A 的后续。和子改进点不同：子改进点是把一件事拆开，前置是先后。只用来提示，不改状态。 |
| 流程图 | 项目的另一个视图：方块是改进点，箭头从前置指向后续，可以拖动、连线、新建。 |
| 类型 | `改进` / `bug` / `新需求`。三种混放在同一个队列里，可以筛选。 |
| 状态 | `待办` / `进行中` / `完成`。 |
| deeplink | 每条改进点可以绑定一个链接，比如 AI 对话链接、`vscode://` 链接、`file:` 本地文件、网页地址。也可以从本机的 Claude Code、Codex 或 codeg 会话里直接选一个填进来。 |
| 会话来源 | 设置里选的、读取本机会话的那个软件：Claude Code、Codex、codeg 三选一，默认不使用。 |
| 项目总览 | 根据项目里的改进点自动汇总出的视图：模块进度、类型分布、可以开始、进行中、完成历史。 |

## 规则

### 项目与模块

- 项目名称不能为空，也不能和其他项目重名。
- 模块名称在同一个项目内不能重名。
- 绑定的文件夹只是记录路径，用来一键打开和找项目自己的图标。文件夹不存在时只做提示，不影响其他功能。
- 选了文件夹而名称没填时，名称用文件夹名。
- 项目图标「自动」时，按这个顺序找，找到就停：
  1. 应用配置明确指定的图标：MyGo 的 `mygo.config.ts/js/mjs` 中 `export default defineConfig({...})` 顶层静态 `icon`；Godot 的 `project.godot` 中 `[application] config/icon="res://..."`；Unity 的 `ProjectSettings/ProjectSettings.asset` 图标 GUID，通过 `Assets` 下的 `.meta` 找到图片。Unity 按默认、Standalone、Android、其他平台的顺序尝试；不读取无关材质或启动画面的 GUID；
  2. `index.html`、`app/root.tsx` 等入口文件里 `<link rel="icon">` 指向的图片；
  3. 约定位置：`favicon`、`public/favicon`、`app/icon`、`src/app/icon`、`assets/icon`、`logo`、`public/logo`、`src-tauri/icons/icon`、`resources/icon`、`build/appicon`、`build/icon`、`app-icon`、`app_icon`、`assets/app-icon`、`assets/app_icon`、`public/app-icon`、`public/app_icon`、`resources/app-icon`、`resources/app_icon`、`icon` 等，每个依次试 `.png`、`.webp`、`.svg`；
  4. 入口文件里 `<link rel="apple-touch-icon">` 指向的图片；
  5. `apple-touch-icon.png`（根目录、`public/`、`static/`）。
- 项目根目录找不到时，先在 workspace 声明的应用中找，再检查直接下一层的应用文件夹；各组按路径名称排序，取首个合格图标。应用标记包括 `package.json`、`index.html`、MyGo 配置、`project.godot` 和 Unity 配置。支持 npm/Yarn `workspaces` 数组或 `{packages: [...]}`，以及 pnpm-workspace.yaml 的顶层 packages 字符串列表（逐行列表或 JSON 格式行内数组）；支持 `*`、`?`、字符集合、`**` 和 `!` 排除，不解释 YAML 标签/别名或复杂表达式。
- 查找受范围限制：workspace 最多 128 个模式、8 层、4096 个目录项、64 个应用；直接子应用另限 4096 个目录项和 64 个应用。跳过 `node_modules`、`dist`、`build`、`out`、`target`、`vendor`、`coverage`、`Library`、`Temp`、`obj`、`Logs`、`Builds` 和隐藏目录。Unity 只为已声明的 GUID 在 `Assets` 下查找，最多 32 层、20000 个目录项，循环检查 2 秒时间预算；成功路径在内存中缓存（最多 128 项），每次使用前重新校验 `.meta` 和图片。配置/入口/单个 `.meta` 最多读 256 KB。
- 不执行项目配置代码：MyGo 的变量、函数调用、插值或对象展开会退回其他检测方式。图片和配置路径拒绝绝对路径、`..` 及指向目录外的符号链接；**不联网**（不取网站图标和 GitHub 头像）。没有可靠图片时仍用默认图标，可手动选择图片。
- 只认按内容判断是 PNG、WebP（不超过 4 MB）或 SVG（扩展名是 `.svg`、内容是 SVG，不超过 1 MB）的图片；ICO 不认。`vite.svg`、`react.svg`、`vue.svg`、`next.svg`、`vercel.svg` 这类脚手架模板自带的图标不认，因为每个项目都一样。PNG 缩到 128 像素保存，WebP 和 SVG 原样保存。
- 检测的时机：绑定或更换文件夹时、图标弹窗里点「重新检测」时、程序启动 3 秒后（把绑定了文件夹的项目都看一遍）。手动选的图标不会被检测覆盖。
- 删除模块时，下面的改进点不删除，变成「未分类」。
- 删除项目会同时删除它的模块和改进点（包括回收站里属于它的）；删除前要确认，并告诉用户会删掉多少条改进点。

### 改进点

- 标题必填，其他字段都可选。类型默认是「改进」。
- 状态**全部由用户手动切换**，可以在三种状态之间任意切换，比如把完成的重新打开。
- **进行中不限数量。**
- 状态切换时记录开始时间和完成时间；重新打开时清除完成时间。项目总览的完成历史依赖这些时间。
- 重新打开（圆圈、`Space`、右键「重新打开」）回到完成前的状态：在进行中时完成的，回到进行中，开始时间保留；从待办直接完成的，回到待办。详情里直接点选状态不受这条影响。
- 待办的顺序由用户拖动决定，表示打算做的顺序。进行中默认按开始的先后排：开始进行（包括重新打开回到进行中、拖到「进行中」标题上）时，它所在的整棵树排到进行中的最后；之后可以拖动调整，拖过的顺序会保留。拖到进行中两条之间时，就放在那里。从只能按开始时间排序的旧版本升级时，现有的进行中按开始时间重排一次。
- 改进点可以移到另一个项目，移动后模块变成「未分类」；它的子改进点一起移过去，也都变成「未分类」，被移动的那条变成顶层。

### 子改进点

- 层数不限；不能把一条改进点放进它自己或它的子孙里。
- 父改进点的状态不随子改进点自动变化，仍然由用户手动切换。
- 父改进点标为完成时（圆圈、`Space`、详情的状态、右键菜单、拖到「已完成」都一样），它下面所有还没完成的子改进点一起标为完成（记下是跟着它完成的），整棵树进「已完成」；本来就完成的子改进点不动。父改进点撤回成未完成时（重新打开、改成待办或进行中，各个入口都一样），只有当时跟着它完成的子改进点撤出完成，各自回到当时的状态（进行中的回到进行中，开始时间保留；待办的回到待办）；本来就完成的保持完成。跟着完成之后又手动改过状态的、移出这棵树的子改进点，算作自己的，不再跟着撤回。这个记录存在数据文件里，重启后照样有效。
- 在队列里拖到另一条的上沿或下沿（各占一行高度的 30%）：移到它前面或后面，和它同一层。顶层的已完成按完成时间排序，没有用户排序：拖到它们的上沿或下沿等于拖到这个分区（见下面「拖动改状态」）。
- 拖到另一条中间（剩下的 40%）：它没有子改进点时「合并」，在它的位置新建一个父改进点，它在前、拖过来的在后；它已经有子改进点时「放入」，成为它的最后一条子改进点。
- 拖到另一条的下沿时再往右移一点（约一层缩进）：插入线跟着缩进一层，显示「成为子改进点」，松手后成为它的最后一条子改进点。它已有子改进点且展开着时，下沿本来就是放到第一条子改进点前面。
- 合并出来的父改进点：标题是第一条子改进点标题的前 6 个字（不足 6 个字用全部）加「等 N 个改进点」，N 是子改进点条数；子改进点增减或第一条变化时自动更新，用户改过标题后不再自动更新。类型和模块跟合并目标一样；两条都完成时是完成，否则是待办。
- 一棵树（顶层改进点和它下面所有的）在队列里只出现在一个分区：里面有进行中的就在「进行中」，否则有待办的在「待办」，否则在「已完成」。筛选时只看符合筛选的那些。
- 筛选时，符合条件的改进点连同它的上级一起显示，不符合的上级变淡，只作上下文。
- 删除父改进点时，子改进点上移一层，补到它原来的位置，不会被一起删除。

### 前置

- 只能在同一个项目里建立；不能是同一条；不能绕成一圈（建立时报错，说明谁已经在等谁）；建立时不能和自己的上级或子孙连。之后拖动改了层级，已有的前置保留。
- 「等待中」是算出来的：自己没完成、还有没完成的前置。**只提示，不限制**：等待中的照样可以开始、完成，状态仍由用户手动切换，也不会自动排序。
- 子改进点不继承上级的前置。
- 删除到回收站时，它的前置和在流程图上的位置跟着进回收站；恢复时，另一条还在、在同一个项目、不会绕成一圈就恢复。另一条也在回收站里时，前置留给它，它恢复时一起回来。彻底删除时一起删掉。
- 移到其他项目时，和留下的改进点之间的前置断开（一起移走的之间保留），提示里写断开了几条；在流程图上的位置清掉，到新项目里重新排。
- 复制给 AI 不带前置。

### 流程图

- 显示当前项目里符合模块和类型筛选的改进点，子改进点也是单独的方块（方块上写着上级）。默认不显示已完成的，连着线的照样显示（变淡）；工具栏可以打开「显示已完成」。
- 位置存在数据文件里。没存过位置的自动排：有连线的按前后排成列（前置在左），没连线的在下面按行排开；第一次拖动或整理时，把当前看到的位置全部存下来，之后新加的排在已有方块的下面。
- 拖动、一键整理、连线、删线可以撤回和重做，切换项目时清空；撤回只撤流程图上的操作，最近一次删除比它们晚时，`Ctrl+Z` 先撤销删除。
- 每个项目的平移和缩放记在本机，第一次打开时显示全部。

### 拖动改状态

- 拖到某个分区上（分区标题、分区里的空白处、已完成里顶层条目的上沿 / 下沿）：改成这个分区的状态。分区收起时，拖到标题上也可以。
- 为了让它真的落到这个分区：拖到「已完成」时，它下面还没完成的子改进点一起标为完成；拖到「待办」时，它下面进行中的子改进点一起退回待办；拖到「进行中」只改它自己。会改动多条时，提示上显示条数。
- 拖到「待办」标题上的顶层改进点，同时排到待办的最前面。
- 拖到待办或进行中里两条顶层改进点之间：放在那个位置，并改成这个分区的状态（会显示「改为待办」或「开始进行」）。
- 子改进点拖到分区上只改状态，仍然留在原来的上级下面。
- 拖到侧栏的某个模块（或「未分类」）上：这一条和它下面所有子改进点一起改成那个模块，位置和状态不变；它们本来都在这个模块里时不算落点。右键「移到模块」仍然只改这一条。
- 状态改变照常记录开始和完成时间，和手动切换一样。
- deeplink 必须是带 scheme 的合法链接（包括 `file:`），点击后交给系统默认程序打开。粘贴本地路径（如 `D:\项目\笔记.md` 或 `\\server\share`）会自动转成 `file:` 链接；`javascript:`、`data:` 这类链接不接受。
- 子改进点自己没有链接时，沿用最近一层有链接的上级的链接（只往上找，父改进点不会用子改进点的）；自己填了就用自己的。只在打开和显示时沿用，不复制到子改进点上，所以上级换了链接会跟着变。设置里可以关闭，默认打开。
- 会话来源一次只用一个，只读不写：不改动、不监听这些软件的会话，也不和它们通信；状态仍由用户手动切换。选了来源后，链接旁边可以「选择会话」，从这个来源的本机会话里选一个填入链接：
  - codeg 的会话填 `codeg://session/<会话编号>`，由 codeg 打开；图标按这条会话实际用的 agent（Claude、Codex、Gemini，其他 agent 用 codeg 的图标）。
  - Codex 的会话填 `codex://threads/<线程 ID>`，由 Codex 打开。
  - Claude Code 的会话填 `claude-session:<会话 ID>`。`claude://` 目前不能直达某个会话，所以由本软件运行 `claude --desktop --resume <会话 ID>`（在会话所在的文件夹里，不弹终端），交给 Claude 桌面版打开。这种链接只在本软件里能打开。
  - 只列用户自己开的会话：Claude Code 和 Codex 的子 agent 会话、codeg 里删除的、委派出去的、聊天和循环会话都不列。
- 会话链接显示成「agent 图标 + 会话名」，会话名每次从本机现查，不存进数据文件，所以在原软件里改名后跟着变。换了来源后，其他来源的会话链接照常能打开，仍显示图标，但会话名查不到，显示「来源 会话 短 ID」。
- 「复制」把标题和备注复制成一段 Markdown，由用户自己粘贴发送；有子改进点时，后面附上它们的任务清单（按层级缩进，完成的打勾），每条子改进点的备注缩进放在它下面。不带链接。备注里的图片换成本机的绝对路径（`![](<…\images\x.png>)`），AI 可以按路径读图；只换复制出去的文字，备注本身不变。

### 多选

- 选中只在界面上，不存进数据文件，切换项目时清空。多条的先后一律按队列从上到下。
- `Shift` 连选的范围是当前显示的行（可以跨分区）；收起、被筛掉的行不算进去。已选中的条目被收起或筛掉后仍然算选中，详情面板的列表里能看到。
- 父改进点和它的子改进点一起选中时，复制、移到其他项目、标为完成、拖动只对最上层那条做一次，下面的跟着它；改为待办、开始进行、改类型、改模块、删除对每条选中的都做。`Tab` / `Shift+Tab` 也是每条依次处理，上级真的移动了，下面选中的才跟着它；上级移不了（比如已经在顶层），下面的自己移。
- `Space`：全部已完成时一起重新打开，否则全部标为完成。`S`：全部进行中时一起退回待办，否则不在进行中的都开始进行。
- 右键单击已选中的行：保留整组，菜单换成批量版；右键单击没选中的行：只选它一条，菜单照旧。
- 从选中的行开始拖：整组一起拖，按原来的先后依次落下。拖到行的上沿 / 下沿：依次排在那里；成为子改进点 / 放入：依次成为它最后的子改进点；拖到「待办」标题：顶层的依次排到待办最前；拖到侧栏模块：整组连同子改进点一起改模块。一组没有「合并」。从没选中的行开始拖，只拖这一条。
- 彻底删除多条：确认一次，说明删几条、有几个子改进点会上移一层。删到回收站不用确认。

### 回收站

- 删除改进点时先进回收站，不用确认，提示里可以撤销（`Ctrl+Z` 也行）；按住 `Shift` 删除是彻底删除，不进回收站，要确认。删父改进点时子改进点照旧上移一层，不跟着进回收站。
- 回收站只有一个，放所有项目删除的改进点；删除项目时，它在回收站里的改进点一起彻底删除。
- 恢复时回到原来的上级下面、原来的次序，状态、时间、模块、备注、链接都是删除时的样子；当时上移的子改进点如果还在原处，就放回它下面；带着完成的关系也恢复。原来的上级不在了（彻底删除、移到其他项目、还在回收站里），放到项目顶层最后；原来的模块不在了，变成「未分类」。一起删的几条一起撤销时，层级照原样。
- 回收站默认保留 30 天，可以改成 7 天、90 天或一直保留；超期的在后台彻底删除。

### 数据

- 所有数据只存在本机的用户数据目录，不上传。唯一联网的地方是检查和下载更新：只读取 GitHub 上公开的 Release 文件，不发送任何数据。
- 备注和项目说明里的图片存在数据目录的 `images/` 里，按内容命名（同一张图只存一份）；Markdown 里写成 `![](image:<文件名>)`，不含机器路径。没有任何备注或项目说明再引用、而且存在超过 24 小时的图片，在程序启动后由后台清掉（删除改进点、删掉图片都会这样清理；24 小时的余量照顾撤销）。回收站里的备注也算引用，彻底删除后才清理。
- 修改立即保存，没有「保存」按钮；程序异常退出也不能丢失已经保存的内容。

### 程序

- 常驻托盘：关闭主窗口只是隐藏；托盘左键打开主窗口，右键菜单有「打开 Vibe Atlas / 快速记录 / 退出」。
- 老板键：全局快捷键，默认不设置。按下时立刻隐藏所有窗口（主窗口和快速记录小窗）；没有窗口在显示时按下，主窗口回来并获得焦点。托盘图标不隐藏。不能和快速记录的快捷键相同。
- 单实例：已经在运行时再次启动，只把已有的主窗口带到前面。
- 主窗口记住大小和位置；队列和详情之间的分隔线可以拖动，宽度会记住。
- 设置（`Ctrl+,`）：左侧竖排分页「常规 / 外观 / 改进点 / 数据 / 更新」，切换时有过渡。常规页分「启动」「全局快捷键」「软件内快捷键」三组：启动里是「开机自动启动」开关（默认关；打开后登录系统时自动启动，只进托盘、不弹主窗口；开关显示系统里的真实状态，在任务管理器里关掉这里也显示关；开发版本不能设置）；全局快捷键里是快速记录和老板键，都可以录制修改（被占用或两个相同时就地提示，并保留原来的；录制时两个全局快捷键都临时释放），快速记录可以恢复默认，老板键可以清除；软件内的快捷键不能修改，入口跳到使用说明的快捷键一节。每张设置卡片的说明收在标题旁的 ⓘ 提示里；改进点页是「子改进点沿用上级的链接」开关和「会话来源」（不使用 / Claude Code / Codex / codeg，四选一，默认不使用）；外观页依次是主题（跟随系统 / 浅色 / 深色）、动态背景、背景图片、毛玻璃、窗口整体透明度（见下面的「视觉效果」），选项按需出现；数据页显示数据文件夹并可一键打开；更新页显示当前版本、检查更新按钮和 GitHub 上的所有版本，以及「自动检查更新」。
- 检查更新：在后台检查 GitHub Releases，快速记录不受影响。「自动检查更新」三选一：启动时检查（默认，启动约 3 秒后检查一次）、定时检查（启动时检查一次，之后每小时 / 每 6 小时 / 每天，默认每天）、不自动检查（只在更新页手动检查）；改了马上生效，不用重启，从别的方式切到定时检查时，离上次检查已经超过间隔就立刻检查一次。取清单时地址带随机参数，刚发布的新版本不会被中间的缓存挡住。github.com 的下载地址 6 秒内不响应或返回错误时（比如本机代理对它超时、返回 504），改走 GitHub API 取同一个文件；检查和下载遇到网络问题或 5xx 时自动重试，共试 3 次；仍然失败时说明原因（比如「GitHub 暂时没有响应（504）……开着代理时，确认代理能访问 GitHub」「连接 GitHub 超时」）。有新版本时主窗口右下角提示「发现新版本 x.y.z」，带「去更新」「稍后」；点「去更新」后提示里用进度条和百分比显示下载进度，下载、校验签名、替换完成后自动重新打开，没有单独的更新窗口。「稍后」或把提示划走，本次运行不再提示这个版本，下次启动再提示。下载或校验失败时提示「更新失败」，带「重试」「去 GitHub」（打开最新的 Release 页面手动下载安装包）和右上角的 ×（和「稍后」一样），原来的版本不受影响。只有用安装包安装（或放在可写文件夹里的免安装版）、带签名打包的版本能自动更新；开发模式和自己打包的版本在更新页说明原因。数据文件不受更新影响。
- 使用说明（`F1`）：弹窗，左侧导览目录，右侧一整篇带样式的说明（流程步骤、状态和类型标签、Markdown 输入与效果对照、按键样式）。点目录平滑滚到对应章节，滚动时高亮当前章节。章节：开始使用、快速记录、队列与状态、改进点详情、前置与流程图、Markdown 备注、项目总览、快捷键。快捷键按「全局（快速记录、老板键）/ 主窗口 / 选中的改进点 / 流程图 / 队列底部的输入框 / 快速记录小窗 / Markdown 编辑器」分组，全局快捷键显示当前设置的值。设置和使用说明互相有入口，同一时间只开一个。
- 视觉风格「暗场 + 信号光」（参照 Next-AIGC）：暗色近黑、亮色偏暖的底色。主窗口分两层：顶栏和侧栏是底层框架，队列、详情、总览放在一块浮起的圆角内容面板里，四周留出间隙；弹窗和菜单近实底、顶边有一道高光；类型用彩色标签，进行中用发光小圆点，数量和时间用等宽字；菜单和对话框打开时带弹簧缓动。亮暗两种主题都适配。
- 动效：所有分段按钮（「队列 / 总览」、状态和类型筛选、详情的状态和类型三段、图标选择器的分类、设置里的单选组）和侧栏选中的项目、模块，选中的底色按弹簧曲线滑到新的一项，切到总览再切回来也接着滑；换项目、打开回收站时内容区淡入，队列和总览互切时各自淡入；队列里改状态换分组、分组和子改进点折叠展开、新增和删除时，其余的行滑到新位置，新出现的行淡入（换项目、换筛选、拖动中不做）；详情面板在空状态、单条、多选之间切换时淡入，链接卡片和输入框互换时淡入；`↑ ↓` 换选中条目时立即切换，不淡入。系统打开「减少动态效果」时都不播放。
- 自建顶栏：主窗口隐藏系统标题栏，只保留系统的最小化、最大化、关闭按钮。顶栏只有应用图标和名字、外观切换（跟随系统 → 浅色 → 深色）；使用说明和设置在侧栏左下角（使用说明在上）；空白处可以拖动窗口，双击最大化。
- 项目控件在队列列顶部，分两行：第一行左边是项目菜单（带项目图标），右边是文件夹和「队列 / 流程图 / 总览」分段切换；第二行是状态筛选和类型筛选。流程图第二行是它自己的工具栏，总览视图只有第一行，放在总览顶部。队列列变窄时，文件夹名、视图、状态和类型的文字收起，只显示图标。
- 视觉效果（设置 → 外观，默认都关闭）：
  - 动态背景：无 / 点阵网格 / 点阵信号，会增加显卡占用。
  - 背景图片：选一张本地图片（PNG、JPG、WebP、GIF、BMP，不超过 20 MB），复制到数据目录的 `wallpapers/` 里；可以调模糊、不透明度、大小（铺满窗口或自定义缩放）、水平和垂直位置，可以暂时隐藏、更换、移除。动态背景叠在图片上面。
  - 毛玻璃：开了动态背景或显示背景图片时，框架（顶栏和侧栏）和内容面板变成毛玻璃，只有面板四周的间隙能看清背景。可以调模糊强度、内容面板不透明度、框架不透明度。同时还有条目悬停辉光、进行中圆点闪烁。
  - 选项按需出现：没有图片时只有「选择图片」，有了图片才出现预览、显示开关、更换、移除；图片显示时才出现模糊、不透明度、大小、位置；开了动态背景或显示图片时才出现毛玻璃，否则只有一行提示。
  - 每组设置都能恢复默认；拖动滑杆时实时预览，设置弹窗的遮罩会暂时淡出，松手后保存。
  - 都没开时这些代码不加载；快速记录小窗始终不显示；系统开了「减少动态效果」时背景静止。
- 窗口整体透明度（设置 → 外观，默认 100%，最低 40%）：整个主窗口连同文字一起变透明，可以透过它看到桌面；和毛玻璃分开调，快速记录小窗不受影响。
- 自建滚动条：侧栏、队列、详情、总览、设置和使用说明不用系统滚动条，改成浮在内容右边的细滑块。滚动或指针移进区域时出现，停下后淡出（设置和使用说明内容长，滑块和浅色轨道一直显示）；指针移到滑块上会变粗，可以拖动，点轨道翻一页。滚轮、键盘、拖动条目时的自动滚动都照常工作。菜单和 Markdown 编辑器仍用系统的细滚动条。

### 项目与模块

- 项目：新建、编辑（右键菜单或项目菜单的「编辑项目」，或双击直接在行内改名，Enter 保存，Esc 放弃）、删除（确认并说明会一起删掉多少条改进点）、拖动排序；重名就地提示。
- 绑定、更换、解除本地文件夹，一键在资源管理器打开；文件夹不存在时标红提示。项目栏的文件夹按钮平时是合上的文件夹图标（文字偏淡），悬停时变亮、图标打开，点击时按下缩一下、图标弹开一次再合上。
- 新建和编辑项目是同一个弹窗（侧栏 `+`，右键或项目菜单的「编辑项目」）：左边是图标，右边是名称和文件夹，三项都能改。选好文件夹后，名称没填就填上文件夹名，图标没手动选时显示检测到的图标（图标右下角标「自动」）；文件夹可以更换、解除。
- 图标：点侧栏里项目或模块的图标，在旁边弹出图标选择（和双击改名一样快），选中立即保存；也可以在「编辑项目」「编辑模块」弹窗里点图标换。项目和模块的右键菜单只有「编辑」和「删除」。选择框的高度跟着窗口可用空间走，列表在里面滚动。最上面是「自动」（项目，按应用配置、网页声明和常见路径检测，支持 workspace 子应用，详见上面的检测规则，可以「重新检测」）或「默认图标」（模块）；下面分三页：图标（80 个内置图标，可以按中文搜索）、Emoji（常用 64 个，也可以输入或粘贴任意 emoji）、图片（选一张本机的 PNG、JPG、WebP、GIF 或 SVG，PNG/JPG/GIF 缩到 128 像素，WebP/SVG 原样存进数据目录）。
- 图标显示在侧栏、项目菜单按钮、详情的模块选择、总览的模块进度、回收站的所属项目，以及快速记录小窗的项目 / 模块列表和底栏。
- 项目说明用 Markdown 写（即时预览），在总览页编辑。
- 模块：新建、编辑（新建和右键菜单的「编辑模块」是同一个弹窗：左边图标、右边名称；或双击直接在行内改名，Enter 保存，Esc 放弃）、删除（下面的改进点变「未分类」）、拖动排序；点击模块就是按模块筛选。有未分类的改进点时，模块列表里显示「未分类」。
- 侧栏显示每个项目、模块还没完成的数量；有进行中的改进点时显示一个小圆点。
- 记住上次打开的项目。

### 改进点与队列

- 队列分三块：进行中（默认按开始先后，可以拖动调整）、待办（拖动排序）、已完成（最近完成的在最上面，每次多显示 50 条）。筛选为「全部」时，三块都可以点标题收起和展开，会记住；默认进行中、待办展开，已完成收起。只看某一种状态时，那一块始终展开。进行中没有条目时也显示标题，方便拖进去；已完成没有条目时，只在拖动时出现。在队列底部新增时，待办会自动展开。
- 队列底部的输入框：Enter 新增到待办最后，Tab 切换类型；在某个模块或类型的筛选下新增时，自动用这个模块和类型。
- 状态：点行首圆圈标为完成或重新打开（回到完成前的状态）；可以开始进行、退回待办；进行中不限数量；自动记录开始和完成时间。行尾悬停或选中时出现的按钮：待办有「开始进行」「标为完成」，进行中只有「标为完成」，都带「复制给 AI」；已完成的行没有这些按钮。右键菜单里，进行中时完成的条目显示「重新打开」（回到进行中）和「改为待办」。
- 详情面板：标题（悬停出现淡底，点击直接编辑）同一行右边放复制给 AI、移到其他项目（没有其他项目时不显示）、删除，分隔线后是关闭。下面是两列属性区（左边淡色属性名，右边是值）：状态是「待办 | 进行中 | 完成」三段，直接点选，当前段用状态色；类型也是「改进 | bug | 新需求」三段，直接点选，当前段用类型色；模块未分类时显示「选择模块」；链接没填时是「添加链接」入口，填了显示成链接卡片（网页显示域名和路径，本地文件显示文件名，点击打开，悬停出现编辑和解除）；时间是一条小时间线（创建 / 开始 / 完成，带等了多久、用了多久，进行中时实时显示已进行多久，悬停显示完整的年月日时分秒）。最下面是带「备注」标题的无边框编辑器，悬停出现淡底、聚焦时出现描边；备注停顿 0.5 秒或离开编辑器时自动保存。「备注」标题右边的「沉浸式编辑」按钮打开沉浸式编辑弹窗（见下面「沉浸式编辑」），打开前先保存面板里还没保存的内容。
- deeplink：保存时检查格式，不合法就地提示且不保存；可以从行内图标、详情面板或快捷键 `O` 打开。子改进点沿用上级的链接时，行内图标变淡，悬停提示「沿用「上级标题」的链接」；详情的链接卡片后面标「沿用「上级标题」」，编辑按钮为这一条单独设置链接，没有解除按钮。
- 选择会话（设置了会话来源时）：详情里「添加链接」旁边多一个「选择会话」，已有链接时悬停出现「改成另一个会话」；点开是一个可以搜索的列表，每行是 agent 图标、会话名和最后修改时间，最近的在最上面。项目绑定了文件夹时默认只列这个文件夹（包括里面的子文件夹）里的会话，「本项目 / 全部」可以切换（`Tab`）；一次画出 200 条，更多的输入文字搜索。`↑ ↓` 选择，`Enter` 填入并保存，`Esc` 关闭。列表只在打开时读取。会话链接在详情里显示成 agent 图标加会话名，悬停显示原始链接；队列行内的链接图标换成 agent 图标，悬停显示会话名。
- 「复制给 AI」：把标题和备注复制成一段 Markdown。
- 单击改进点选中并在右侧打开详情；双击（不在圆圈、箭头和行内按钮上）直接在行内改名，`Enter` 或点别处保存，`Esc` 放弃；`Shift+Enter` 保存后在下面新开一行同级改进点直接起名（同一个上级、同类型、同模块，待办），起好名再按 `Shift+Enter` 继续往下加，`Enter` 或点别处保存这一条，空着按 `Esc` 或点别处就不加。光标停在标题中间按 `Shift+Enter` 时，从光标处切开：前半段留作这一条的标题，后半段挪进新开那一行（光标在最前），像编辑器里换行一样；选中了文字、光标在最前或最后时不切开。在挪过来文字的新行里按 `Esc` 放弃，原来那一条的标题恢复完整。上级是顶层的进行中或已完成时，新加的是待办，会出现在「待办」里。
- 右键菜单：改状态、复制、打开链接、添加子改进点、移到上一级（子改进点才有）、移到模块、移到其他项目、删除（进回收站；按住 `Shift` 是彻底删除，需确认，有子改进点时说明它们会上移一层）。
- 子改进点：队列里按层级缩进，每层有一条引导线；父改进点行首有箭头可以收起和展开（会记住），行内显示子孙的完成进度（小圆环和「完成数/总数」）。拖动任何一行（包括进行中和已完成）：拖到另一行的上沿或下沿时显示一条插入线，移到它前后；在下沿再往右移一点，插入线缩进一层并显示「成为子改进点」；拖到中间时这一行高亮并显示「合并」或「放入」；拖到某个分区时整块高亮，标题右边显示「开始进行」「改为待办」「移到待办最前」「标为完成」。拖到侧栏的模块或「未分类」上时，那一行高亮，数量换成「移入」徽标（会改动多条时带条数），松手后改成那个模块；子改进点一起改；队列正按别的模块筛选时，这些条目离开队列，提示「已移到「模块名」」（带子改进点时说明条数）。拖动时原来的行变淡并留下虚线框，下面的子改进点一起变淡；鼠标上跟着一张浮起的卡片，带着子改进点时显示「+N」，后面叠着一两层卡片；指到松手不会有变化的地方时，卡片变淡、去掉强调色。插入线出现时从左往右画出来，在下沿左右移动时平滑缩进。松手后队列立刻更新。侧栏的项目和模块拖动排序时，拖着的那一行同样浮起成卡片，整个窗口的鼠标都显示成「抓住」。
- 详情面板不列出子改进点，子改进点在左边队列里查看和切换；子改进点的详情顶部显示上级路径（点击跳到上级）。
- 多选（规则见上面「多选」）：单击只选一条；`Ctrl`（macOS 上是 `⌘`）+ 单击加选或取消；`Shift` + 单击从上次点的那条连选到这一条，`Ctrl+Shift` + 单击在原有选择上再加一段；`Shift+↑ ↓` 连选；`Ctrl+A` 全选当前显示的行；`Esc` 或点空白处取消。在队列的空白处（行与行之外：两侧留白、分区之间、列表下面）按下拖动，拉出半透明的选择框，碰到的行随框实时选中，按住 `Ctrl` / `Shift` 开始时在原有选择上追加；拖到队列上下边缘时自动滚动。选中的行用选中底色，相邻的连成一整块；多选时，键盘所在的那一条多一道细描边，行尾按钮不再常显。
- 多选后的批量操作：右键菜单（顶部显示「已选 N 条」，有重新打开 / 开始进行 / 标为完成 / 改为待办中适用的几项、复制给 AI、移到模块、移到其他项目、删除 N 条）；快捷键 `Space`、`S`、`C` / `Ctrl+C`、`Delete`、`Tab` / `Shift+Tab` 作用于整组（`O`、`Enter` / `E` 多选时不起作用）。复制多条时每条按单条的格式，条与条之间用 `---` 分隔，提示「已复制 N 条」。
- 多选时的详情面板：顶部是一叠卡片的图标和「已选 N 条」（数字变化时轻轻滑入），同一行右边是复制给 AI、移到其他项目、删除和取消选择；下面一条状态分布条（进行中 / 待办 / 完成按条数分段着色，下面列各状态的条数）；再下面是和单条详情同样的属性区，状态三段、类型、模块直接改整组（都一样时显示那个值，不一样时状态和类型的三段都不亮，模块显示「分在 N 个模块」）；最下面列出已选的条目（状态图标、类型图标、标题、模块），上级也选中的往里缩进，新加入的一行滑入，单击一行只选它并打开它的详情，悬停出现 × 把它移出选择。
- 一起拖动：从选中的行开始拖时整组一起走，原来的位置都留下虚线框，浮起的卡片显示总条数「+N」；插入线、分区高亮和提示上的条数按整组计算。
- 添加子改进点：右键菜单「添加子改进点」后，队列底部的输入框前面出现「↳ 父改进点标题」标记，输入标题按 Enter 添加为它的子改进点（类型默认跟父改进点一样，`Tab` 切换；模块跟父改进点一样；可以连续添加，父改进点收起时会自动展开）。按 `Esc` 或点标记上的 × 回到普通记录。
- 按状态（全部 / 进行中 / 待办 / 完成，每项带数量）、类型（队列顶部，再点一次选中的类型即取消）和模块（侧栏）筛选，可以组合，一键清除；切换项目时清空。
- 键盘：`N` 新增、`↑ ↓`（或 `J K`）选择、`←` 收起子改进点或回到上级、`→` 展开子改进点或进入第一条、`Space` 完成 / 重新打开、`S` 开始 / 退回待办、`C` 或 `Ctrl+C` 复制、`O` 打开链接、`Enter` 或 `E` 编辑标题（队列里显示着这一条时直接在行内改名，否则在详情里编辑）、`Tab` 缩进（成为上面最近一条同级改进点的最后一条子改进点，上面没有同级时不动）、`Shift+Tab` 取消缩进（移到上一级，放在原来上级的后面）、`Delete` 删除到回收站、`Shift+Delete` 彻底删除、`Ctrl+Z` 撤销上一次删除、`Esc` 取消选择；`Shift+↑ ↓` 连选、`Ctrl+A` 全选（见上面「多选」）。

### 前置与流程图

- 详情面板「链接」下面是「前置」和「后续」两行：每条显示成小标签（状态图标和标题，还没完成的前置带一圈进行中色的细边），点击打开那一条，悬停出现 × 去掉；「添加前置」「添加后续」弹出可以搜索的列表，只列可以连的（同一个项目、不是自己的上级或子孙、不会绕成一圈、还没连过），没完成的在前。
- 队列里等待中的改进点，行内显示沙漏（在等多条时带条数），悬停列出在等哪几条。
- 流程图（队列顶部切换到「流程图」，第一次打开时才加载，不影响启动和快速记录）：右边是同一个详情面板，宽度单独记住。
  - 方块：状态圆圈（点击完成 / 重新打开）、标题（最多两行）、类型、上级、模块、备注和等待标记；进行中的带进行中色，已完成的变淡、标题划线。右键是和队列同一份菜单。
  - 连线：从前置的右边连到后续的左边，带箭头；前置没完成时是流动的虚线（系统要求减少动态效果时不流动），完成后是实线。悬停或选中时变成主色，中间出现删除按钮。
  - 鼠标：点方块选中（`Ctrl` 加选 / 减选，`Shift` 加选），拖方块移动（选中的一组一起移动，吸附到 8 像素的点阵），拖空白处框选（按住 `Ctrl` / `Shift` 追加），点空白处取消选择；右键或中键拖动画布；滚轮在指针处缩放（20%–200%），`Shift` + 滚轮或触控板横向滑动左右移动；双击方块编辑标题，双击空白处在那里新建。
  - 连线和新建：指针移到方块上，两侧出现圆点；从右侧圆点拉到另一条，那条等这条；从左侧圆点拉出，这条等那条；拉的时候目标方块高亮，不能连时变红，松手提示原因。拉到空白处松手，在那里出现输入框，起好名就新建一条并连上。新建框里 `Enter` 保存，`Shift+Enter` 保存后在右边接着写下一条（自动等前一条），`Tab` 换类型，`Esc` 或空着离开就不建；模块和类型按当前的筛选。
  - 工具栏：类型筛选、显示已完成；新建（`N`，在画布中间）、一键整理（排好后显示全部）、撤回（`Ctrl+Z`）、重做（`Ctrl+Shift+Z` / `Ctrl+Y`）。右下角：缩小、比例（点击回到 100%）、放大、显示全部。
  - 键盘：选中的方块和队列一样用 `Space` `S` `C` `O` `Enter` / `E` `Delete` `Esc`；`Ctrl+A` 选中全部方块；选中连线时 `Delete` 删除它、`Esc` 取消。
  - 没有要显示的改进点时，中间提示双击或按 `N` 新建（已完成的被隐藏时提示可以打开）。

### 回收站

- 删除（`Delete`、详情和多选详情的删除按钮、右键菜单的删除）不弹确认，改进点进回收站，右下角提示「『标题』已移到回收站」（多条时「已把 N 条移到回收站」），带「撤销」按钮；`Ctrl+Z` 撤销最近一次删除。撤销后放回原处并选中它们。
- 彻底删除：`Shift+Delete`，或按住 `Shift` 点删除按钮、右键菜单的删除；先确认（说明不进回收站、无法恢复，以及有几个子改进点会上移）。按住 `Shift` 时，删除按钮变红、图标换成火焰、提示变成「彻底删除，不进回收站」；右键菜单开着时按下 `Shift`，「删除」实时变成「彻底删除」，快捷键提示变成 `Shift+Delete`。
- 侧栏左下角（使用说明上面）是「回收站」入口，显示条数，有改进点进来时图标跳一下；点击后内容面板变成回收站，再点一次、或点项目、模块，回到队列。
- 回收站视图：顶部是「回收站」、条数和保留天数（点击打开 设置 → 数据），右边是「清空回收站」（确认后彻底删除全部），选中条目后换成「已选 N 条 · 恢复 · 彻底删除 · 取消选择」。条目按删除的日期分组（今天、昨天、几月几日），最新的在前；每条显示类型图标、状态图标、标题、所属项目、「N 个子改进点已上移，恢复时放回」、删除时间（悬停显示完整时间）和「N 天后清除」；悬停出现「恢复到原来的位置」和「彻底删除」。单击选一条，`Ctrl` 加选，`Shift` 连选，双击恢复；`↑ ↓`（或 `J K`）移动，`Shift+↑ ↓` 连选，`Ctrl+A` 全选，`Enter` 恢复，`Delete` 彻底删除（确认），`Esc` 先取消选择、再按回到队列。回收站空时显示「回收站是空的」和说明。底部一行按键提示。
- 从回收站恢复后提示「『标题』已恢复到『项目』」，带「查看」按钮，点击打开那个项目并在队列里选中它。
- 设置 → 数据：「回收站保留多久」7 天 / 30 天（默认）/ 90 天 / 一直保留。程序启动约 5 秒后、之后每 6 小时清理一次超期的条目；改短时立刻清理。

### Markdown 编辑器

- 光标所在的行显示源码，其他行显示渲染效果；离开编辑器后整篇渲染。改进点备注和项目说明用同一个编辑器。
- 斜杠命令：在行首或空格后输入 `/`，光标下方弹出插入菜单：正文、标题 1–3、列表、编号列表、任务、引用、代码块、表格、分隔线、图片（打开系统的选择文件窗口，可以多选）。继续输入可以筛选，中文名、拼音首字母、英文都行（如「代码」`dmk` `code`）；`↑ ↓` 选择，`Enter` 或 `Tab` 执行，`Esc` 关闭并留下 `/`，输入空格、光标离开或编辑器失去焦点时关闭；代码里不弹出。行格式加在这一行上（替换原有的标题、列表或引用标记），代码块、表格、分隔线在空行上直接占这一行，否则放在这一行下面。所有 Markdown 编辑器都有，包括快速记录小窗。
- 查找替换：`Ctrl+F` 查找、`Ctrl+H` 替换，编辑器顶部出现一条和应用同样式的查找栏（区分大小写、全字匹配、正则、全选、替换、全部替换），匹配处高亮。
- 自动配对：输入 `(` `[` `{` `` ` `` `"` 时补上另一半（紧挨着文字时不补），再输入右半边时跳过，在一对空括号中间退格两边一起删掉；连续输入三个反引号得到代码块的开头。选中文字后输入这些符号，或 `*` `_` `~`，就把文字包起来。输入法组字时都不触发。
- 支持标题、粗体、斜体、删除线、行内代码、链接（点击打开；正在编辑的链接用 `Ctrl+点击`）、引用、代码块（有语法高亮；光标不在块里时显示成带边框的卡片，顶部一条标题栏显示语言和「复制」按钮，三个反引号隐藏，光标进去后恢复显示）、列表（回车自动续写）、可以直接点击勾选的任务框、分隔线。
- 快捷键：`Ctrl+B` 粗体、`Ctrl+I` 斜体、`Ctrl+E` 行内代码、`Ctrl+Shift+X` 删除线、`Ctrl+K` 链接；支持撤销和重做。格式都是开关：选区已经在这种格式里时，再按一次取消整段的这种格式。
- 划词工具栏：用鼠标划选（拖选、双击、`Shift` + 点击）后，选区上方浮出一条工具栏（上方放不下时在下方），依次是标题（正文 / 标题 1–3 的下拉）、粗体、斜体、删除线、行内代码、链接、引用、列表、任务、代码块；选区已有的格式高亮，指针停一会儿显示名称和快捷键。标题、引用、列表、任务作用于选区涉及的每一行（列表和任务互相切换时替换行首标记，编号列表变成无序列表）；代码块把这些行包进 ```` ``` ````，已在代码块里时去掉围栏；链接已存在时取消链接。键盘选择不弹出；打字、点到别处、离开编辑器或按 `Esc` 时收起。
- 图片：`Ctrl+V` 粘贴截图或复制的图片、把图片文件拖进编辑器（拖动时显示落点），支持 PNG、JPG、WebP、GIF、BMP，单张不超过 20 MB；粘贴从网页、Word、在线文档复制的图文混排内容时，转成 Markdown（标题、粗体、斜体、删除线、行内代码、代码块、链接、列表、引用、分隔线、表格），里面的图片保存到本地、留在原来的位置：内嵌的图片直接保存，网络图片下载后保存（下载失败时保留原链接），本机的图片文件读取后保存；有图片没能保存时提示条数，保存超过一会儿时显示「正在保存粘贴的图片」。内容里没有图片时按纯文本粘贴（从代码编辑器复制的代码不会被转换）；粘贴到代码块里也是纯文本。图片单独占一行，一次放多张时同一行并排。图片显示成圆角卡片，按原比例不裁切：单张最高 20rem，并排时等高 9rem 自动换行；加载时是闪光占位，加载完淡入；悬停微微浮起，右上角出现「删除」（删掉这一处，可以撤销）；文件不见了时显示「图片不见了」。光标进入图片那一行时，源码和图片都显示，图片不会跳动。
- 大图预览：点图片打开，铺满窗口的暗色背景上显示图片：滚轮在指针处缩放、拖动平移、双击在「适应窗口」和「原始大小」之间切换、`← →` 或两侧按钮切换同一篇里的上一张 / 下一张、`+ - 0` 放大 / 缩小 / 适应、`Esc` 或点空白处关闭；底部工具条有张数、缩小、比例、放大、原始大小 / 适应窗口、用默认应用打开、关闭。快速记录小窗里点图片直接用系统的看图软件打开。

### 沉浸式编辑

- 从详情面板「备注」右边的展开按钮打开，编辑当前选中的改进点的备注，同样停顿 0.5 秒自动保存；`Esc`、× 或点外面关闭时先等保存完成，再让面板里的编辑器显示最新内容。选中多条或这一条被删掉时自动关闭。
- 顶栏：直接改标题（`Enter` 或点别处保存，`Esc` 先放弃修改再关弹窗）、三段式状态、类型；上一条、下一条（`Alt+PageUp` / `Alt+PageDown`，按队列里当前看得到的顺序，弹窗不关）；复制给 AI；大纲开关；「排版」；铺满窗口（`F11`）；关闭。
- 大纲：左侧列出备注里的标题，按层级缩进，点击跳过去并把光标放在那里，光标所在的章节高亮；没有标题时提示怎么写。可以收起。
- 折叠：标题左侧悬停出现箭头，点击收起或展开这一节，收起后显示一个占位块，点它展开。
- 「排版」：行宽窄、中、宽三档；字号 13–22px；专注模式（光标所在的段落或代码块正常显示，其他变淡）；打字机滚动（打字和用键盘移动光标时，所在的行保持在中间，鼠标点击不跳）。
- 底部状态栏：字数（中文按字、其他文字按词，不算 Markdown 标记和链接地址）、行数、约几分钟读完；保存状态（未保存 / 保存中… / 已保存 · 时间 / 保存失败）；右侧是常用快捷键提示。
- 铺满窗口、大纲、行宽、字号、专注模式、打字机滚动这些选择记在本机，下次打开沿用。

### 快速记录小窗

- 全局快捷键（默认 `Ctrl+Alt+Space`）在任何软件上方呼出，出现在鼠标所在屏幕的上方居中；窗口高度跟着内容变，平时只有一行标题和底栏，顶边位置不动。
- 输入标题按 `Enter` 保存，可以连续记；`Tab` 切换类型，`Esc` 关闭（输入法有候选时 `Esc` 只取消候选；没保存的内容留到下次呼出）。
- `Shift+Enter` 展开详情：Markdown 即时预览的备注（和主窗口同一个编辑器）和可选的 deeplink，和标题一起保存。备注里 `Ctrl+Enter` 保存，链接里 `Enter` 保存，`Esc` 回到标题（详情为空时收起）。设置了会话来源时，链接一行右边有「选择会话」（`Ctrl+L`），在小窗里展开和项目、模块一样的列表，选中后填入链接并展开详情；会话链接在不编辑时显示成 agent 图标加会话名。小窗呼出时不读任何会话。
- 项目和模块在底栏，点击或按 `Ctrl+P` / `Ctrl+M` 打开可搜索的列表，显示各自未完成的数量；输入的名字不存在时可以直接新建。标题里 `↑ ↓` / `Ctrl+↑ ↓` 也能轮换项目 / 模块。
- 默认记到主窗口当前打开的项目，没有时用上次记录用的项目；保存后底栏短暂显示「已记到 项目 / 模块」和本次已记的条数。
- 点到别处时自动隐藏；还没有项目时，直接在小窗里输入名字新建第一个项目，也可以打开主窗口。

### 项目总览

- 项目说明；全部、待办、进行中、完成的数量和总进度条。
- 模块进度（含「未分类」），点击跳到这个模块的队列；类型分布和未完成数，点击按类型筛选队列。
- 「可以开始」：设了前置、前置都已完成的待办（没有时不显示）；进行中列表；完成记录按天分组，可以按模块和类型筛选。点击任何一条，跳到队列里对应的那一条。

### 数据

- 数据存在本机 `%AppData%\Vibe Atlas\vibe-atlas.db`（SQLite），设置里可以一键打开所在文件夹。每次修改立即写入磁盘，强制结束进程也不丢已经保存的内容。
- 数据文件带版本号；遇到更新版本程序写的数据文件时拒绝打开，不覆盖。
- 备注里的图片在同一个文件夹的 `images/` 里；没人引用的图片在启动后约 10 秒由后台清理（见上面「规则 → 数据」）。项目和模块图标用的图片也放在这里，在用的不会被清理。
