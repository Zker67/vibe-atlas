## 定位

个人开发者所有 vibe 项目的管理中枢：随手记下每个想法，一条条推进，项目的全貌自然积累出来。

使用场景：一个人在一台电脑上做氛围编程。看到运行结果时，改进点、bug、新需求会一起冒出来，但一次只发一条给 AI。Vibe Atlas 负责三件事：

1. **快速记下**所有想法，不打断手上的工作；
2. 让人**挑出下一条**，复制出去，自己发给 AI；
3. 由人**自己标记进度**；积累下来的记录自动汇总成项目总览。

和 Linear 的区别：不联网、不等待、不同步，没有成员、Cycle、估点和权限，也不内置 AI。

## 使用流程

```text
看到结果 ──▶ 快捷键呼出 ──▶ 连记几条（改进 / bug / 新需求）
                                    │
                                    ▼
                  在待办里排序，挑一条 ──▶ 复制，自己发给 AI
                                    │       （可选：把对话链接存为 deeplink）
                                    ▼
                      手动标为「进行中」 ──▶ 做完后手动打勾「完成」
                                    │
                                    ▼
                  项目总览：各模块进度、完成历史自动汇总
```

## 核心概念

| 概念 | 说明 |
|---|---|
| 项目 | 一个完整项目，比如「规则恐怖」。有名称和项目说明（Markdown），可以绑定一个本地文件夹，也可以不绑。 |
| 模块 | 项目里的一块内容，比如武器系统、人物、关卡、UI。只属于一个项目。 |
| 改进点 | 一件具体要做的事。有标题、类型、状态，可以选模块，可选备注（Markdown）和 deeplink。 |
| 类型 | `改进` / `bug` / `新需求`。三种混放在同一个队列里，可以筛选。 |
| 状态 | `待办` / `进行中` / `完成`。 |
| deeplink | 每条改进点可以绑定一个链接，比如 AI 对话链接、`vscode://` 链接、`file:` 本地文件、网页地址。 |
| 项目总览 | 根据项目里的改进点自动汇总出的视图：模块进度、类型分布、进行中、完成历史。 |

## 规则

### 项目与模块

- 项目名称不能为空，也不能和其他项目重名。
- 模块名称在同一个项目内不能重名。
- 绑定的文件夹只是记录路径，用来一键打开。文件夹不存在时只做提示，不影响其他功能。
- 删除模块时，下面的改进点不删除，变成「未分类」。
- 删除项目会同时删除它的模块和改进点；删除前要确认，并告诉用户会删掉多少条改进点。

### 改进点

- 标题必填，其他字段都可选。类型默认是「改进」。
- 状态**全部由用户手动切换**，可以在三种状态之间任意切换，比如把完成的重新打开。
- **进行中不限数量。**
- 状态切换时记录开始时间和完成时间；重新打开时清除完成时间。项目总览的完成历史依赖这些时间。
- 待办的顺序由用户拖动决定，表示打算做的顺序。
- 改进点可以移到另一个项目，移动后模块变成「未分类」。
- deeplink 必须是带 scheme 的合法链接（包括 `file:`），点击后交给系统默认程序打开。粘贴本地路径（如 `D:\项目\笔记.md` 或 `\\server\share`）会自动转成 `file:` 链接；`javascript:`、`data:` 这类链接不接受。
- 「复制」把标题和备注复制成一段 Markdown，由用户自己粘贴发送。

### 数据

- 所有数据只存在本机的用户数据目录，不联网。
- 修改立即保存，没有「保存」按钮；程序异常退出也不能丢失已经保存的内容。

## 已实现的功能

第一期原型（Windows），2026-11-07 完成实现，**等待用户验收**。验收清单见 [第一期计划](../plans/2026-11-07-prototype/00-overview.md#用户验收场景)，实施情况见 [实施报告](../plans/2026-11-07-prototype/09-implementation-report.md)。

### 程序

- 常驻托盘：关闭主窗口只是隐藏；托盘左键打开主窗口，右键菜单有「打开 Vibe Atlas / 快速记录 / 退出」。
- 单实例：已经在运行时再次启动，只把已有的主窗口带到前面。
- 主窗口记住大小和位置；队列和详情之间的分隔线可以拖动，宽度会记住。
- 设置（`Ctrl+,`）：修改快速记录快捷键（被占用时提示，并保留原来的）、恢复默认；主题跟随系统 / 浅色 / 深色；视觉效果；显示数据文件夹并可一键打开；快捷键一览。
- 视觉风格「暗场 + 信号光」（参照 Next-AIGC）：暗色近黑、亮色偏暖的底色。主窗口分两层：顶栏和侧栏是底层框架，队列、详情、总览放在一块浮起的圆角内容面板里，四周留出间隙；弹窗和菜单近实底、顶边有一道高光；类型用彩色标签，进行中用发光小圆点，数量和时间用等宽字；菜单和对话框打开时带弹簧缓动。亮暗两种主题都适配。
- 自建顶栏：主窗口隐藏系统标题栏，只保留系统的最小化、最大化、关闭按钮。顶栏只有应用图标和名字、外观切换（跟随系统 → 浅色 → 深色）；设置在侧栏左下角；空白处可以拖动窗口，双击最大化。
- 项目控件在队列列顶部，分两行：第一行是项目菜单、文件夹、「队列 / 总览」分段切换；第二行是状态筛选和类型筛选。总览视图只有第一行，放在总览顶部。队列列变窄时，文件夹名、视图、状态和类型的文字收起，只显示图标。
- 视觉效果（设置里切换，默认关闭）：动态背景二选一（点阵网格 / 点阵信号），加上框架和内容面板的毛玻璃（文字后面只透出模糊的光，内容面板最不透明；只有面板四周的间隙能看清背景）、条目悬停辉光、进行中圆点闪烁。关闭时这些代码不加载；快速记录小窗始终不显示；系统开了「减少动态效果」时背景静止。

### 项目与模块

- 项目：新建、重命名、删除（确认并说明会一起删掉多少条改进点）、拖动排序；重名就地提示。
- 绑定、更换、解除本地文件夹，一键在资源管理器打开；文件夹不存在时标红提示。
- 项目说明用 Markdown 写（即时预览），在总览页编辑。
- 模块：新建、重命名、删除（下面的改进点变「未分类」）、拖动排序；点击模块就是按模块筛选。有未分类的改进点时，模块列表里显示「未分类」。
- 侧栏显示每个项目、模块还没完成的数量；有进行中的改进点时显示一个小圆点。
- 记住上次打开的项目。

### 改进点与队列

- 队列分三块：进行中（按开始时间）、待办（拖动排序）、已完成（默认折叠，最近完成的在最上面，每次多显示 50 条）。
- 队列底部的输入框：Enter 新增到待办最后，Tab 切换类型；在某个模块或类型的筛选下新增时，自动用这个模块和类型。
- 状态：点行首圆圈标为完成或重新打开；可以开始进行、退回待办；进行中不限数量；自动记录开始和完成时间。
- 详情面板：标题、状态、类型、模块、deeplink、备注、创建 / 开始 / 完成时间。标题同一行右边直接放复制给 AI、移到其他项目、删除、关闭四个按钮；状态是一个按钮，放在类型前面，点一下按「待办 → 进行中 → 完成 → 待办」轮换。备注停顿 0.5 秒或离开编辑器时自动保存。
- deeplink：保存时检查格式，不合法就地提示且不保存；可以从行内图标、详情面板或快捷键 `O` 打开。
- 「复制给 AI」：把标题和备注复制成一段 Markdown。
- 右键菜单：改状态、复制、打开链接、移到模块、移到其他项目、删除（需确认）。
- 按状态（全部 / 进行中 / 待办 / 完成，每项带数量）、类型（队列顶部，再点一次选中的类型即取消）和模块（侧栏）筛选，可以组合，一键清除；切换项目时清空。只看完成时已完成直接展开。
- 键盘：`N` 新增、`↑ ↓`（或 `J K`）选择、`Space` 完成 / 重新打开、`S` 开始 / 退回待办、`C` 或 `Ctrl+C` 复制、`O` 打开链接、`Enter` 编辑标题、`Delete` 删除、`Esc` 取消选择。

### Markdown 编辑器

- 光标所在的行显示源码，其他行显示渲染效果；离开编辑器后整篇渲染。改进点备注和项目说明用同一个编辑器。
- 支持标题、粗体、斜体、删除线、行内代码、链接（点击打开；正在编辑的链接用 `Ctrl+点击`）、引用、代码块（有语法高亮）、列表（回车自动续写）、可以直接点击勾选的任务框、分隔线。
- 快捷键：`Ctrl+B` 粗体、`Ctrl+I` 斜体、`Ctrl+E` 行内代码、`Ctrl+Shift+X` 删除线、`Ctrl+K` 链接；支持撤销和重做。

### 快速记录小窗

- 全局快捷键（默认 `Ctrl+Alt+Space`）在任何软件上方呼出，出现在鼠标所在屏幕的上方居中。
- 输入标题按 Enter 保存，可以连续记；`Tab` 切换类型，`↑ ↓` 切换项目，`Ctrl+↑ ↓` 切换模块，`Esc` 关闭（输入法有候选时 `Esc` 只取消候选）。
- 默认记到主窗口当前打开的项目，没有时用上次记录用的项目；每次保存后在小窗里列出「已记到 某项目」。
- 点到别处时自动隐藏；还没有项目时提示，并可以一键打开主窗口。

### 项目总览

- 项目说明；全部、待办、进行中、完成的数量和总进度条。
- 模块进度（含「未分类」），点击跳到这个模块的队列；类型分布和未完成数，点击按类型筛选队列。
- 进行中列表；完成记录按天分组，可以按模块和类型筛选。点击任何一条，跳到队列里对应的那一条。

### 数据

- 数据存在本机 `%AppData%\Vibe Atlas\vibe-atlas.db`（SQLite），设置里可以一键打开所在文件夹。每次修改立即写入磁盘，强制结束进程也不丢已经保存的内容。
- 数据文件带版本号；遇到更新版本程序写的数据文件时拒绝打开，不覆盖。
