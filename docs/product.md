## 定位

个人开发者所有 vibe 项目的管理中枢：随手记下每个想法，一条条推进，项目的全貌自然积累出来。

使用场景：一个人在一台电脑上做氛围编程。看到运行结果时，改进点、bug、新需求会一起冒出来，但一次只发一条给 AI。Vibe Atlas 负责三件事：

1. **快速记下**所有想法，不打断手上的工作；
2. 让人**挑出下一条**，复制出去，自己发给 AI；
3. 由人**自己标记进度**；积累下来的记录自动汇总成项目总览。

和 Linear 的区别：不联网、不等待、不同步，没有成员、Cycle、估点和权限，也不内置 AI。

## 使用流程

```text
看到结果 ──▶ 快捷键呼出 ──▶ 连记几条（改进 / bug / 新需求）
                                    │
                                    ▼
                  在待办里排序，挑一条 ──▶ 复制，自己发给 AI
                                    │       （可选：把对话链接存为 deeplink）
                                    ▼
                      手动标为「进行中」 ──▶ 做完后手动打勾「完成」
                                    │
                                    ▼
                  项目总览：各模块进度、完成历史自动汇总
```

## 核心概念

| 概念 | 说明 |
|---|---|
| 项目 | 一个完整项目，比如「规则恐怖」。有名称和项目说明（Markdown），可以绑定一个本地文件夹，也可以不绑。 |
| 模块 | 项目里的一块内容，比如武器系统、人物、关卡、UI。只属于一个项目。 |
| 改进点 | 一件具体要做的事。有标题、类型、状态，可以选模块，可选备注（Markdown）和 deeplink。 |
| 子改进点 | 放在另一条改进点下面的改进点，层数不限。上面那条叫父改进点。每一条都有自己的类型、状态和模块。 |
| 类型 | `改进` / `bug` / `新需求`。三种混放在同一个队列里，可以筛选。 |
| 状态 | `待办` / `进行中` / `完成`。 |
| deeplink | 每条改进点可以绑定一个链接，比如 AI 对话链接、`vscode://` 链接、`file:` 本地文件、网页地址。 |
| 项目总览 | 根据项目里的改进点自动汇总出的视图：模块进度、类型分布、进行中、完成历史。 |

## 规则

### 项目与模块

- 项目名称不能为空，也不能和其他项目重名。
- 模块名称在同一个项目内不能重名。
- 绑定的文件夹只是记录路径，用来一键打开。文件夹不存在时只做提示，不影响其他功能。
- 删除模块时，下面的改进点不删除，变成「未分类」。
- 删除项目会同时删除它的模块和改进点；删除前要确认，并告诉用户会删掉多少条改进点。

### 改进点

- 标题必填，其他字段都可选。类型默认是「改进」。
- 状态**全部由用户手动切换**，可以在三种状态之间任意切换，比如把完成的重新打开。
- **进行中不限数量。**
- 状态切换时记录开始时间和完成时间；重新打开时清除完成时间。项目总览的完成历史依赖这些时间。
- 重新打开（圆圈、`Space`、右键「重新打开」）回到完成前的状态：在进行中时完成的，回到进行中，开始时间保留；从待办直接完成的，回到待办。详情里直接点选状态不受这条影响。
- 待办的顺序由用户拖动决定，表示打算做的顺序。进行中默认按开始的先后排：开始进行（包括重新打开回到进行中、拖到「进行中」标题上）时，它所在的整棵树排到进行中的最后；之后可以拖动调整，拖过的顺序会保留。拖到进行中两条之间时，就放在那里。从只能按开始时间排序的旧版本升级时，现有的进行中按开始时间重排一次。
- 改进点可以移到另一个项目，移动后模块变成「未分类」；它的子改进点一起移过去，也都变成「未分类」，被移动的那条变成顶层。

### 子改进点

- 层数不限；不能把一条改进点放进它自己或它的子孙里。
- 父改进点的状态不随子改进点自动变化，仍然由用户手动切换。
- 父改进点标为完成时（圆圈、`Space`、详情的状态、右键菜单、拖到「已完成」都一样），它下面所有还没完成的子改进点一起标为完成，整棵树进「已完成」。已完成的父改进点撤回成未完成时（重新打开、改成待办或进行中，各个入口都一样），它下面已完成的子改进点一起退回待办；父改进点改成进行中时，子改进点也是退回待办，不会一起开始。
- 在队列里拖到另一条的上沿或下沿（各占一行高度的 30%）：移到它前面或后面，和它同一层。顶层的已完成按完成时间排序，没有用户排序：拖到它们的上沿或下沿等于拖到这个分区（见下面「拖动改状态」）。
- 拖到另一条中间（剩下的 40%）：它没有子改进点时「合并」，在它的位置新建一个父改进点，它在前、拖过来的在后；它已经有子改进点时「放入」，成为它的最后一条子改进点。
- 拖到另一条的下沿时再往右移一点（约一层缩进）：插入线跟着缩进一层，显示「成为子改进点」，松手后成为它的最后一条子改进点。它已有子改进点且展开着时，下沿本来就是放到第一条子改进点前面。
- 合并出来的父改进点：标题是第一条子改进点标题的前 6 个字（不足 6 个字用全部）加「等 N 个改进点」，N 是子改进点条数；子改进点增减或第一条变化时自动更新，用户改过标题后不再自动更新。类型和模块跟合并目标一样；两条都完成时是完成，否则是待办。
- 一棵树（顶层改进点和它下面所有的）在队列里只出现在一个分区：里面有进行中的就在「进行中」，否则有待办的在「待办」，否则在「已完成」。筛选时只看符合筛选的那些。
- 筛选时，符合条件的改进点连同它的上级一起显示，不符合的上级变淡，只作上下文。
- 删除父改进点时，子改进点上移一层，补到它原来的位置，不会被一起删除。

### 拖动改状态

- 拖到某个分区上（分区标题、分区里的空白处、已完成里顶层条目的上沿 / 下沿）：改成这个分区的状态。分区收起时，拖到标题上也可以。
- 为了让它真的落到这个分区：拖到「已完成」时，它下面还没完成的子改进点一起标为完成；拖到「待办」时，它下面进行中的子改进点一起退回待办；拖到「进行中」只改它自己。会改动多条时，提示上显示条数。
- 拖到「待办」标题上的顶层改进点，同时排到待办的最前面。
- 拖到待办或进行中里两条顶层改进点之间：放在那个位置，并改成这个分区的状态（会显示「改为待办」或「开始进行」）。
- 子改进点拖到分区上只改状态，仍然留在原来的上级下面。
- 拖到侧栏的某个模块（或「未分类」）上：这一条和它下面所有子改进点一起改成那个模块，位置和状态不变；它们本来都在这个模块里时不算落点。右键「移到模块」仍然只改这一条。
- 状态改变照常记录开始和完成时间，和手动切换一样。
- deeplink 必须是带 scheme 的合法链接（包括 `file:`），点击后交给系统默认程序打开。粘贴本地路径（如 `D:\项目\笔记.md` 或 `\\server\share`）会自动转成 `file:` 链接；`javascript:`、`data:` 这类链接不接受。
- 子改进点自己没有链接时，沿用最近一层有链接的上级的链接（只往上找，父改进点不会用子改进点的）；自己填了就用自己的。只在打开和显示时沿用，不复制到子改进点上，所以上级换了链接会跟着变。设置里可以关闭，默认打开。
- 「复制」把标题和备注复制成一段 Markdown，由用户自己粘贴发送；有子改进点时，后面附上它们的任务清单（按层级缩进，完成的打勾），每条子改进点的备注缩进放在它下面。不带链接。

### 数据

- 所有数据只存在本机的用户数据目录，不联网。
- 修改立即保存，没有「保存」按钮；程序异常退出也不能丢失已经保存的内容。

### 程序

- 常驻托盘：关闭主窗口只是隐藏；托盘左键打开主窗口，右键菜单有「打开 Vibe Atlas / 快速记录 / 退出」。
- 单实例：已经在运行时再次启动，只把已有的主窗口带到前面。
- 主窗口记住大小和位置；队列和详情之间的分隔线可以拖动，宽度会记住。
- 设置（`Ctrl+,`）：左侧竖排分页「快速记录 / 改进点 / 外观 / 数据」，切换时有过渡。快速记录页修改全局快捷键（被占用时提示，并保留原来的）、恢复默认，并有入口跳到使用说明的快捷键一节；改进点页是「子改进点沿用上级的链接」开关；外观页依次是主题（跟随系统 / 浅色 / 深色）、动态背景、背景图片、毛玻璃、窗口整体透明度（见下面的「视觉效果」），选项按需出现；数据页显示数据文件夹并可一键打开。
- 使用说明（`F1`）：弹窗，左侧导览目录，右侧一整篇带样式的说明（流程步骤、状态和类型标签、Markdown 输入与效果对照、按键样式）。点目录平滑滚到对应章节，滚动时高亮当前章节。章节：开始使用、快速记录、队列与状态、改进点详情、Markdown 备注、项目总览、快捷键。快捷键按「全局 / 主窗口 / 选中的改进点 / 队列底部的输入框 / 快速记录小窗 / Markdown 编辑器」分组，全局快捷键显示当前设置的值。设置和使用说明互相有入口，同一时间只开一个。
- 视觉风格「暗场 + 信号光」（参照 Next-AIGC）：暗色近黑、亮色偏暖的底色。主窗口分两层：顶栏和侧栏是底层框架，队列、详情、总览放在一块浮起的圆角内容面板里，四周留出间隙；弹窗和菜单近实底、顶边有一道高光；类型用彩色标签，进行中用发光小圆点，数量和时间用等宽字；菜单和对话框打开时带弹簧缓动。亮暗两种主题都适配。
- 自建顶栏：主窗口隐藏系统标题栏，只保留系统的最小化、最大化、关闭按钮。顶栏只有应用图标和名字、外观切换（跟随系统 → 浅色 → 深色）；使用说明和设置在侧栏左下角（使用说明在上）；空白处可以拖动窗口，双击最大化。
- 项目控件在队列列顶部，分两行：第一行是项目菜单、文件夹、「队列 / 总览」分段切换；第二行是状态筛选和类型筛选。总览视图只有第一行，放在总览顶部。队列列变窄时，文件夹名、视图、状态和类型的文字收起，只显示图标。
- 视觉效果（设置 → 外观，默认都关闭）：
  - 动态背景：无 / 点阵网格 / 点阵信号，会增加显卡占用。
  - 背景图片：选一张本地图片（PNG、JPG、WebP、GIF、BMP，不超过 20 MB），复制到数据目录的 `wallpapers/` 里；可以调模糊、不透明度、大小（铺满窗口或自定义缩放）、水平和垂直位置，可以暂时隐藏、更换、移除。动态背景叠在图片上面。
  - 毛玻璃：开了动态背景或显示背景图片时，框架（顶栏和侧栏）和内容面板变成毛玻璃，只有面板四周的间隙能看清背景。可以调模糊强度、内容面板不透明度、框架不透明度。同时还有条目悬停辉光、进行中圆点闪烁。
  - 选项按需出现：没有图片时只有「选择图片」，有了图片才出现预览、显示开关、更换、移除；图片显示时才出现模糊、不透明度、大小、位置；开了动态背景或显示图片时才出现毛玻璃，否则只有一行提示。
  - 每组设置都能恢复默认；拖动滑杆时实时预览，设置弹窗的遮罩会暂时淡出，松手后保存。
  - 都没开时这些代码不加载；快速记录小窗始终不显示；系统开了「减少动态效果」时背景静止。
- 窗口整体透明度（设置 → 外观，默认 100%，最低 40%）：整个主窗口连同文字一起变透明，可以透过它看到桌面；和毛玻璃分开调，快速记录小窗不受影响。
- 自建滚动条：侧栏、队列、详情、总览、设置和使用说明不用系统滚动条，改成浮在内容右边的细滑块。滚动或指针移进区域时出现，停下后淡出（设置和使用说明内容长，滑块和浅色轨道一直显示）；指针移到滑块上会变粗，可以拖动，点轨道翻一页。滚轮、键盘、拖动条目时的自动滚动都照常工作。菜单和 Markdown 编辑器仍用系统的细滚动条。

### 项目与模块

- 项目：新建、重命名（右键菜单，或双击直接在行内改名，Enter 保存，Esc 放弃）、删除（确认并说明会一起删掉多少条改进点）、拖动排序；重名就地提示。
- 绑定、更换、解除本地文件夹，一键在资源管理器打开；文件夹不存在时标红提示。
- 项目说明用 Markdown 写（即时预览），在总览页编辑。
- 模块：新建、重命名（右键菜单，或双击直接在行内改名，Enter 保存，Esc 放弃）、删除（下面的改进点变「未分类」）、拖动排序；点击模块就是按模块筛选。有未分类的改进点时，模块列表里显示「未分类」。
- 侧栏显示每个项目、模块还没完成的数量；有进行中的改进点时显示一个小圆点。
- 记住上次打开的项目。

### 改进点与队列

- 队列分三块：进行中（默认按开始先后，可以拖动调整）、待办（拖动排序）、已完成（最近完成的在最上面，每次多显示 50 条）。筛选为「全部」时，三块都可以点标题收起和展开，会记住；默认进行中、待办展开，已完成收起。只看某一种状态时，那一块始终展开。进行中没有条目时也显示标题，方便拖进去；已完成没有条目时，只在拖动时出现。在队列底部新增时，待办会自动展开。
- 队列底部的输入框：Enter 新增到待办最后，Tab 切换类型；在某个模块或类型的筛选下新增时，自动用这个模块和类型。
- 状态：点行首圆圈标为完成或重新打开（回到完成前的状态）；可以开始进行、退回待办；进行中不限数量；自动记录开始和完成时间。行尾悬停或选中时出现的按钮：待办有「开始进行」「标为完成」，进行中只有「标为完成」，都带「复制给 AI」；已完成的行没有这些按钮。右键菜单里，进行中时完成的条目显示「重新打开，回到进行中」和「改为待办」。
- 详情面板：标题（悬停出现淡底，点击直接编辑）同一行右边放复制给 AI、移到其他项目（没有其他项目时不显示）、删除，分隔线后是关闭。下面是两列属性区（左边淡色属性名，右边是值）：状态是「待办 | 进行中 | 完成」三段，直接点选，当前段用状态色；类型显示成彩色标签；模块未分类时显示「选择模块」；链接没填时是「添加链接」入口，填了显示成链接卡片（网页显示域名和路径，本地文件显示文件名，点击打开，悬停出现编辑和解除）；时间是一条小时间线（创建 / 开始 / 完成，带等了多久、用了多久，进行中时实时显示已进行多久，悬停显示完整的年月日时分秒）。最下面是带「备注」标题的无边框编辑器，悬停出现淡底、聚焦时出现描边；备注停顿 0.5 秒或离开编辑器时自动保存。
- deeplink：保存时检查格式，不合法就地提示且不保存；可以从行内图标、详情面板或快捷键 `O` 打开。子改进点沿用上级的链接时，行内图标变淡，悬停提示「沿用「上级标题」的链接」；详情的链接卡片后面标「沿用「上级标题」」，编辑按钮为这一条单独设置链接，没有解除按钮。
- 「复制给 AI」：把标题和备注复制成一段 Markdown。
- 单击改进点选中并在右侧打开详情；双击（不在圆圈、箭头和行内按钮上）直接在行内改名，`Enter` 或点别处保存，`Esc` 放弃；`Shift+Enter` 保存后在下面新开一行同级改进点直接起名（同一个上级、同类型、同模块，待办），起好名再按 `Shift+Enter` 继续往下加，`Enter` 或点别处保存这一条，空着按 `Esc` 或点别处就不加。上级是顶层的进行中或已完成时，新加的是待办，会出现在「待办」里。
- 右键菜单：改状态、复制、打开链接、添加子改进点、移到上一级（子改进点才有）、移到模块、移到其他项目、删除（需确认，有子改进点时说明它们会上移一层）。
- 子改进点：队列里按层级缩进，每层有一条引导线；父改进点行首有箭头可以收起和展开（会记住），行内显示子孙的完成进度（小圆环和「完成数/总数」）。拖动任何一行（包括进行中和已完成）：拖到另一行的上沿或下沿时显示一条插入线，移到它前后；在下沿再往右移一点，插入线缩进一层并显示「成为子改进点」；拖到中间时这一行高亮并显示「合并」或「放入」；拖到某个分区时整块高亮，标题右边显示「开始进行」「改为待办」「移到待办最前」「标为完成」。拖到侧栏的模块或「未分类」上时，那一行高亮，数量换成「移入」徽标（会改动多条时带条数），松手后改成那个模块；子改进点一起改；队列正按别的模块筛选时，这些条目离开队列，提示「已移到「模块名」」（带子改进点时说明条数）。拖动时原来的行变淡并留下虚线框，下面的子改进点一起变淡；鼠标上跟着一张浮起的卡片，带着子改进点时显示「+N」，后面叠着一两层卡片；指到松手不会有变化的地方时，卡片变淡、去掉强调色。插入线出现时从左往右画出来，在下沿左右移动时平滑缩进。松手后队列立刻更新。侧栏的项目和模块拖动排序时，拖着的那一行同样浮起成卡片，整个窗口的鼠标都显示成「抓住」。
- 详情面板不列出子改进点，子改进点在左边队列里查看和切换；子改进点的详情顶部显示上级路径（点击跳到上级）。
- 添加子改进点：右键菜单「添加子改进点」后，队列底部的输入框前面出现「↳ 父改进点标题」标记，输入标题按 Enter 添加为它的子改进点（类型默认跟父改进点一样，`Tab` 切换；模块跟父改进点一样；可以连续添加，父改进点收起时会自动展开）。按 `Esc` 或点标记上的 × 回到普通记录。
- 按状态（全部 / 进行中 / 待办 / 完成，每项带数量）、类型（队列顶部，再点一次选中的类型即取消）和模块（侧栏）筛选，可以组合，一键清除；切换项目时清空。
- 键盘：`N` 新增、`↑ ↓`（或 `J K`）选择、`←` 收起子改进点或回到上级、`→` 展开子改进点或进入第一条、`Space` 完成 / 重新打开、`S` 开始 / 退回待办、`C` 或 `Ctrl+C` 复制、`O` 打开链接、`Enter` 或 `E` 编辑标题（队列里显示着这一条时直接在行内改名，否则在详情里编辑）、`Tab` 缩进（成为上面最近一条同级改进点的最后一条子改进点，上面没有同级时不动）、`Shift+Tab` 取消缩进（移到上一级，放在原来上级的后面）、`Delete` 删除、`Esc` 取消选择。

### Markdown 编辑器

- 光标所在的行显示源码，其他行显示渲染效果；离开编辑器后整篇渲染。改进点备注和项目说明用同一个编辑器。
- 支持标题、粗体、斜体、删除线、行内代码、链接（点击打开；正在编辑的链接用 `Ctrl+点击`）、引用、代码块（有语法高亮）、列表（回车自动续写）、可以直接点击勾选的任务框、分隔线。
- 快捷键：`Ctrl+B` 粗体、`Ctrl+I` 斜体、`Ctrl+E` 行内代码、`Ctrl+Shift+X` 删除线、`Ctrl+K` 链接；支持撤销和重做。

### 快速记录小窗

- 全局快捷键（默认 `Ctrl+Alt+Space`）在任何软件上方呼出，出现在鼠标所在屏幕的上方居中；窗口高度跟着内容变，平时只有一行标题和底栏，顶边位置不动。
- 输入标题按 `Enter` 保存，可以连续记；`Tab` 切换类型，`Esc` 关闭（输入法有候选时 `Esc` 只取消候选；没保存的内容留到下次呼出）。
- `Shift+Enter` 展开详情：Markdown 即时预览的备注（和主窗口同一个编辑器）和可选的 deeplink，和标题一起保存。备注里 `Ctrl+Enter` 保存，链接里 `Enter` 保存，`Esc` 回到标题（详情为空时收起）。
- 项目和模块在底栏，点击或按 `Ctrl+P` / `Ctrl+M` 打开可搜索的列表，显示各自未完成的数量；输入的名字不存在时可以直接新建。标题里 `↑ ↓` / `Ctrl+↑ ↓` 也能轮换项目 / 模块。
- 默认记到主窗口当前打开的项目，没有时用上次记录用的项目；保存后底栏短暂显示「已记到 项目 / 模块」和本次已记的条数。
- 点到别处时自动隐藏；还没有项目时，直接在小窗里输入名字新建第一个项目，也可以打开主窗口。

### 项目总览

- 项目说明；全部、待办、进行中、完成的数量和总进度条。
- 模块进度（含「未分类」），点击跳到这个模块的队列；类型分布和未完成数，点击按类型筛选队列。
- 进行中列表；完成记录按天分组，可以按模块和类型筛选。点击任何一条，跳到队列里对应的那一条。

### 数据

- 数据存在本机 `%AppData%\Vibe Atlas\vibe-atlas.db`（SQLite），设置里可以一键打开所在文件夹。每次修改立即写入磁盘，强制结束进程也不丢已经保存的内容。
- 数据文件带版本号；遇到更新版本程序写的数据文件时拒绝打开，不覆盖。
