## 可能做（还没决定）

| 功能 | 可能的用处 | 不确定的地方 |
|---|---|---|
| 搜索 | 在当前项目或全部项目里搜标题和备注 | 第一期有筛选，先看够不够用 |
| 导出与导入 | 导出 JSON 做备份或迁移，导出 Markdown 方便阅读 | 第一期可以直接复制数据文件来备份 |
| 全部项目的总览 | 把所有项目的进度放在一页里看 | 第一期的项目列表已经显示各项目的数量 |
| 「取消」或「搁置」状态 | 决定不做的改进点不用删除，留在历史里 | 多一个状态就多一份操作负担 |
| 记录时用前缀指定类型 | 快速记录时输入 `bug:` 开头就自动设成 bug | 第一期已经能用键盘选类型 |
| 复制并开始 | 一键完成「复制」和「标为进行中」 | 两步合成一步是否真的更顺手 |
| Markdown 表格 | 备注里写表格 | 即时预览编辑表格的成本较高 |
| 表格编辑辅助 | 表格里 `Tab` 跳到下一格、自动对齐列宽 | 现在斜杠命令能插入表格，粘贴也能转成表格，编辑辅助成本偏高 |
| 备注的历史版本 | 定时存快照，可以回到某个时间点 | 要改数据库，先看撤销够不够用 |
| 沉浸式编辑的只读阅读模式 | 完全渲染、不显示任何源码 | 实时预览已经接近，收益不大 |
| 预制提示词片段 | 常用的提示词带标签存起来，一键插入备注 | 是否真的比复制粘贴方便。完整版的提示词管理已放弃 |
| 项目归档 | 做完的项目从列表里收起来 | 项目多了才需要 |
| 流程图小地图 | 卡片多了以后，在角落里看全图、点哪里跳到哪里 | 现在有「显示全部」和缩放，卡片多到什么程度才需要 |
| 总览导出为 Markdown | 把项目总览放进仓库或发给别人 | 先看总览本身够不够用 |
| Linux 版 | 所选桌面框架也支持 Linux | 目前没有需求 |
