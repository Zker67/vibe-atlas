# 设置分页、新增使用说明

> 状态：`[partial]`：已实现，等用户在真实窗口里验收。

## 来源

用户反馈（2026-11-07）：

- 设置弹窗不够现代，应该分 tab。
- 快捷键要分类；不能改的快捷键不放在设置里，改成使用说明的一部分。
- 使用说明放在设置按钮上面，也是弹窗，要现代：有样式渲染（不是纯文本），有导览。

## 不变量

- 快速记录快捷键的录制、占用提示、恢复默认行为不变。
- 主题、视觉效果、数据文件夹的设置项不变，只换排布。
- 只改前端，不改 Go 端和数据。
- 快速记录小窗不加载使用说明和设置的代码。

## 排布

```text
设置（Ctrl+,）                          使用说明（F1）
┌────────────┬──────────────────┐     ┌────────────┬──────────────────────┐
│ ⚡ 快速记录 │ 标题 + 一句说明    │     │ 导览        │ 一整篇连续的说明       │
│ 🎨 外观     │ ┌ 设置卡片 ─────┐ │     │ ▌开始使用   │ ## 开始使用            │
│ 🗄 数据     │ └──────────────┘ │     │  快速记录   │ 步骤卡片、标签、按键    │
│            │                  │     │  …          │ ## 快速记录 …          │
└────────────┴──────────────────┘     └────────────┴──────────────────────┘
```

- 两个弹窗都是左侧竖排导航，选中项有滑动的高亮块；右侧内容区内部滚动，弹窗高度固定。
- 设置：tab 切换（快速记录 / 外观 / 数据）；「快速记录」页底部有入口跳到使用说明的快捷键一节。
- 使用说明：左侧目录点击后平滑滚到对应章节，滚动时高亮当前章节。章节：开始使用、快速记录、队列与状态、改进点详情、Markdown 备注、项目总览、快捷键。
- 快捷键一节分组：全局、选择与导航、改进点操作、队列输入框、快速记录小窗、Markdown 编辑器。全局快捷键显示当前设置的值，并能跳到设置修改。
- 侧栏左下角：「使用说明 F1」在「设置 Ctrl+,」上面。两个弹窗互斥，打开一个会关掉另一个。
