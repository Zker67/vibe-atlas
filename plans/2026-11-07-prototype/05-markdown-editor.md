# 第 5 步：Markdown 即时预览编辑

> 状态：`[partial]`：已实现，我能自验的检查已通过，等待用户验收。实施情况见 [09-implementation-report.md](./09-implementation-report.md)。

## 目标

把改进点备注和项目说明的普通输入框，换成边写边渲染的 Markdown 编辑器，效果类似 Obsidian 的实时预览：光标所在的地方显示 Markdown 源码，其他地方显示渲染后的样子。

## 本期支持的写法

| 写法 | 要求 |
|---|---|
| 标题（1 到 3 级） | 渲染成对应大小 |
| 粗体、斜体、删除线、行内代码 | 渲染样式 |
| 无序列表、有序列表 | 渲染样式，回车自动续写下一项 |
| 任务框 `- [ ]` | 渲染成可以直接点击勾选的框 |
| 引用 | 渲染样式 |
| 代码块 | 等宽字体和背景；有基础的语法高亮更好，但不强求 |
| 链接 | 渲染成可点击的链接，点击交给系统打开 |
| 分隔线 | 渲染样式 |

表格和图片不在本期（见 [docs/backlog.md](../../docs/backlog.md)）。

## 编辑体验

- 自动保存，没有「保存」按钮。
- 中文输入法正常：候选框位置正确，不丢字、不重复上屏。
- 支持撤销和重做。
- 常用快捷键：加粗、斜体、行内代码、插入链接。
- 改进点备注和项目说明用同一个编辑器。
- 备注很长时，编辑器在自己的区域内滚动，不撑开整个页面。

## 完成标准

- 用户：能完成验收场景第 5 步（写包含多种写法的备注，边写边看到渲染效果，中文输入正常）。
- 我自验：类型检查和 lint 通过；Markdown 内容保存后再读回来完全一致，渲染不会改动原文。

## 做的时候再定

- 光标离开以后才渲染，还是光标所在的一整块都显示源码。以手感为准，实现后请用户试。
- 代码块高亮支持哪些语言。
