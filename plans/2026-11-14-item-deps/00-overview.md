# 前置依赖与流程图：改进点之间的先后顺序，自建画布

> 状态：`[done]`：已实现，随 0.5.0 发布，用户在真实窗口里试用后要求发布（2026-11-14）
>
> 来源：用户 2026-11-14 提出「需要有流程图，然后改进点可以有前置依赖关系」，参考 IndieArk 的 20045 项目中心（任务协作的流程图：`@xyflow/react` + `@dagrejs/dagre`，`task_links` 表）。先做了只读分析；用户又提出「白板自建，不用别人那种的」，回复「那你做吧，按你的」后实施。本计划从 [backlog](../../docs/backlog.md) 的「改进点之间的关联」移出。

## 目标

1. **前置依赖**：改进点 A → B 表示 B 要等 A 做完（A 是 B 的前置，B 是 A 的后续）。与子改进点（拆分）是两回事：子改进点是「一件事拆成几件」，前置是「先后顺序」。
2. **阶段 1（不靠画布）**：详情面板加「前置 / 后续」两行，搜索当前项目的改进点添加、点 × 去掉；队列行在「等待中」（有没完成的前置）时显示沙漏标记，悬停列出在等哪几条；项目总览加「可以开始」（设了前置、前置都已完成的待办）。
3. **阶段 2（自建画布）**：项目多一个「流程图」视图，在队列和总览之间。方块是改进点，连线是前置关系；平移缩放、拖动、框选、连线、拖到空白处新建并自动连上、一键整理、撤回 / 重做，全部自己写，不引入画布库。

## 规则（定稿）

- 只能在同一个项目里建立；不能连自己；不能成环（报错说明谁已经在等谁）。
- 建立时不能和自己的上级或子孙连（父完成会带着子完成，混在一起说不清）；之后拖动改了层级，已有的关系保留，不自动删除。
- 「等待中」是算出来的：自己没完成、有没完成的前置。**只提示，不限制**：等待中的照样可以开始、完成，状态仍只由用户手动切换。
- 子改进点不继承上级的前置。
- 删除进回收站时，它的前置关系和画布位置跟着进回收站；恢复时，另一头还在、同一个项目、不会成环才恢复。另一头也在回收站里时，关系转交给它，等它恢复时一起回来。彻底删除时一起删除。
- 移到其他项目：和留下的改进点之间的关系断开（一起移走的之间保留），画布位置清掉；提示里写断开了几条。
- 复制给 AI 不带前置关系；快速记录小窗不加任何东西（记录要快）。

## 流程图（定稿）

- 显示当前项目、符合模块和类型筛选的改进点，铺平显示（子改进点也是独立的方块，方块上写着上级）。默认不显示已完成的，连着线的已完成仍显示（变淡）；工具栏可以打开「显示已完成」。
- 位置存在本机数据里（`item_canvas`）。没存过位置的自动排：有连线的按「前置在左、后续在右」分层，没有连线的在下方按行排开；第一次拖动或整理时，把当前看到的位置全部存下来，之后新加的改进点排在已有方块的下方。
- 鼠标：左键点方块选中（`Ctrl` 加选 / 减选，`Shift` 加选），拖方块移动（选中的一组一起移动），拖空白处框选，右键或中键拖动画布，滚轮缩放（`Shift` + 滚轮、触控板横向滑动左右移动）；双击方块编辑标题；双击空白处在那里新建一条；从方块右侧圆点拉到另一个方块 = 那条等这条，从左侧圆点拉出 = 这条等那条；拉到空白处松手，在那里新建一条并自动连上。
- 连线：前置已完成画实线，没完成画流动的虚线；点连线选中，`Delete` 删除，悬停时中点有 ×。
- 键盘：`D` / `S` / `C` / `O` / `Enter` / `Delete` / `Esc` 和队列一样作用于选中的方块；`Ctrl+A` 选中全部方块；`N` 在画布中间新建；`Ctrl+Z` / `Ctrl+Shift+Z`（`Ctrl+Y`）撤回 / 重做画布上的操作（移动、整理、加连线、删连线），比最后一次删除早的才撤回画布，否则照旧撤销删除。
- 工具栏：类型筛选、显示已完成、一键整理、撤回、重做；右下角缩放（缩小、比例〔点一下回到 100%〕、放大、显示全部）。
- 每个项目的平移和缩放记在本机（`localStorage`），第一次打开时显示全部。
- 右键方块：和队列行同一份菜单。右侧是同一个详情面板。

## 第二轮优化（定稿）

来源：用户试用后提出「上下级要在一起有特殊显示，是一个节点」「连线手感和周边提示都没有，看看 20045 是怎么调教的」「白板不需要改进、bug、新需求的筛选，一键整理、新增、撤回重做要图标和文字」。参考 20045 `TaskFlow.tsx` 的调教：`connectionRadius 28`、圆点常显、指针旁提示、快捷键面板、对齐参考线、空白处右键菜单、虚线占位卡。

- **上下级合成一张卡片**：最上面显示着的那一条是卡片头，下面每个显示着的子改进点一行（按层级缩进，树形线），卡片头写子改进点完成了几条（如 2/5），卡片带一层叠起来的边。每一行有自己的状态圆圈、两侧圆点、右键菜单，可以单独选中、改名、连线。拖卡片是整张移动。同一张卡片里两条之间的前置从右边绕出去再回来。上级没显示时，子改进点自己成卡片（写着上级）。位置按卡片头存，子改进点以前单独存的位置在卡片里时不用，不改数据结构。
- **拉线手感**：卡片头的圆点一直淡淡地显示，指针在卡片上时全部显示；拉线时能连的一侧圆点亮起、不能连的变淡；在卡片上落到最近的一行，在卡片外 28 像素内吸到最近的能连的圆点，线头跟着吸过去；指针旁边写松手后谁等谁或不能连的原因；拉到空白处出现虚线占位卡片；`Esc` 取消。
- **周边提示**：左下角操作说明（键帽和小鼠标，可收起，记在本机）；空白处右键菜单（在这里新建、全选、撤回 / 重做哪一步、一键整理、显示全部），连线右键可删除；删线后提示可撤回；指针所在卡片和选中改进点的连线加粗。
- **对齐**：只拖一张卡片时，边和中线离别的卡片 6 像素（屏幕）以内就对齐过去并显示参考线，否则吸附点阵。
- **工具栏**：去掉类型筛选（流程图也不再受队列的类型筛选影响，新建默认「改进」，`Tab` 换类型）；新建、一键整理、撤回、重做、显示已完成都是图标加文字，撤回 / 重做悬停写着是哪一步。
- 不做：小地图（记进 backlog）。

## 不变量

- **记录要快**：快速记录小窗不引用任何新代码；流程图的代码按需加载（`React.lazy`），不进主窗口首屏。
- **人工驱动**：前置不改变任何状态，不自动排序、不拦截。
- **本地优先**：不新增依赖，不联网。
- **跨平台**：画布只用 Pointer Events、`wheel`（`ctrlKey` 即触控板捏合）和 CSS transform，WebView2 和 WKWebView 都能用。
- 队列、总览、回收站已有行为不变；`mygo.ts` 只由 `bun run generate` 生成。

- 2026-11-14 实施。和分析时说的相比有两处取舍：

  - 方块大小固定（224 × 72，标题最多两行），连线的端点和排布都按固定尺寸算，不用逐个测量。
- 依赖关系在代码里叫 `dep`（`Dep`、`item_deps`），因为 `link` 已经是 deeplink 的名字。
- 验证：`go vet`、`go test ./...`、`bun test tests`（40 个）、`typecheck`、`lint`、`bun run build` 通过；打包冒烟测试 `"ok": true`，`flow` 的 11 项都通过，原有各项不变。流程图单独打成一个按需加载的文件（`flow-view-*.js`），不进主窗口首屏。

- 2026-11-14 第二轮优化（见上「第二轮优化」）。纯计算新增 `cardsOf`、`cardEdges`、`cardHeight`、`rowMiddle`、`snapToGuides`、`nearestPort`、`stepLabel`，排布支持不同高度的卡片。验证：`bun test tests`（50 个）、`typecheck`、`lint`、`go vet`、`go test ./...`、`bun run build` 通过；打包冒烟测试 `"ok": true`，`flow` 的 15 项都通过（新增子改进点在上级卡片里、工具栏、拉线到子改进点、空白处右键菜单）。冒烟测试要加 `WEBVIEW2_USER_DATA_FOLDER` 指到临时目录：不加时和本机程序共用 `localStorage`，本机收起过沉浸式编辑的大纲会让 `immersive` 检查失败（与本次改动无关），已写进 [operations.md](../../docs/operations.md)。

- 2026-11-14 第三轮（用户反馈「拉出来之后位置不太对，没有对齐，可以缩放把新建内容都放在可视范围内」「没选中东西时右侧面板意义不大」「新建框的提示用 · 分隔，按键没有样式」）：查明位置偏移的原因是新建框自动聚焦时浏览器滚动了 `overflow-hidden` 的画布（画布和左下角的操作说明一起被推到左边）；改为不滚动聚焦，画布滚动时归零。新建框按 `draftSpot` 对齐（下一列、同一行、附近卡片、点阵，不盖住别的卡片），出现后 `revealView` 让它和连着的卡片都在可见范围内（必要时缩小）；流程图没选中时不显示详情面板，出现面板时把选中的卡片移进可见范围；新建框的按键改成键帽，不用 · 分隔。

- 2026-11-14 第四轮：用户提出「完成快捷键不要空格，空格应该能按住然后左键移动白板」「D 是完成，因为 Done」。完成 / 重新打开从 `Space` 改为 `D`（队列、流程图、提示、菜单、使用说明、冒烟测试同步）；流程图里按住 `Space` 左键拖动画布（指针在画布上或焦点在画布里时生效，光标变成手），上面「不用 `Space` + 左键拖动画布」的取舍随之取消。等待标记的悬停提示改成「在等「X」做完」，多条时竖排列出，不再挤成一行。

- 2026-11-14 发布 0.5.0 后：用户提出「这里能显示三行，为什么只用了两行」。卡片头的标题最多三行：按卡片的字体量出标题宽度，要第三行时卡片头高 20 像素（`headHeight`），连线端点、排布、对齐都跟着算；两行以内的卡片不变。使用说明「队列与状态」按用户要求重写：重要操作在前（一张「做什么 / 怎么做」的表，按键用键帽），拖动、子改进点、回收站分小节，细节放最后、字小一号，文字精简。随 0.5.1 发布。
