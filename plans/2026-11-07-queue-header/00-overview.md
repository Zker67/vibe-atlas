# 项目控件挪进队列列，新增状态筛选

> 状态：`[partial]`：已实现，等用户在真实窗口里验收。

## 来源

用户反馈（2026-11-07）：顶栏里的项目控件（项目名、文件夹、队列 / 总览、类型筛选）和「待办 / 进行中 / 完成」都应该在中间列（队列列）的空间里，按更现代的方式排布。确认的方案是 A + b：

- **A**：项目控件从顶栏挪到队列列顶部，宽度跟着队列列走；顶栏只留应用图标、名字和外观按钮。
- **b**：在队列里新增**状态筛选**（全部 / 进行中 / 待办 / 完成），和类型筛选放在一起；详情里切换单条状态的按钮保留不动。

## 不变量

- 详情列的状态切换、快捷键（Space、S、J/K 等）行为不变。
- 筛选只存在内存里，切换项目时清空，和类型筛选一致；不写数据库，不改 Go 端。
- 「清除筛选」同时清掉类型、模块、状态三种筛选。
- 从总览点一条跳到队列时，挡住它的筛选（包括状态）会被清掉。

## 排布

```text
┌ 侧栏 ┬──────────── 队列列 ─────────────┬──── 详情列 ────┐
│      │ 项目名 ▾  📁        [队列|总览] │ 待办 进行中 完成 │  ← 两边都是 h-12，下边线对齐
│      │ 全部 52 · 进行中 3 · 待办 9 · 完成 40   ✦ 🐞 💡 ✕ │
│      │ 队列……                          │ 详情……         │
```

- 第一行：项目菜单、文件夹按钮、右侧的「队列 / 总览」分段控件（浅底轨道 + 浮起的选中块）。
- 第二行：左边是状态筛选，每项带数量（按当前类型和模块筛选后的数量）；右边是类型筛选，只放三种类型，再点一次选中的类型就取消（去掉和状态筛选重复的「全部」）；有筛选时显示「清除筛选」。
- 队列列变窄时，文件夹名、类型文字、状态文字依次收起，只显示图标。
- 总览视图没有队列列：第一行放在总览面板顶部，没有第二行。

## 状态筛选的显示规则

| 筛选 | 队列显示 |
|---|---|
| 全部 | 和现在一样：进行中、待办（可拖动排序）、可折叠的已完成 |
| 进行中 | 只显示进行中 |
| 待办 | 只显示待办，仍可拖动排序 |
| 完成 | 只显示已完成，直接展开，仍按 50 条分页 |

在「进行中」或「完成」筛选下新增的条目（新增总是待办）不会显示，沿用现有提示「已记下，但当前筛选不显示它」。
