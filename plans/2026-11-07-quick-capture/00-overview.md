# 快速记录小窗改版：随内容伸缩、详情区、可搜索可新建的项目和模块

> 状态：`[partial]`：已实现，等用户验收
>
> 来源：用户 2026-11-07 反馈「快速添加面板交互别扭：无法切换项目和模块，下面空空的却占着空间；Shift+Enter 应该展开详情区并支持渲染；整体要更现代」。

## 问题

1. 窗口固定 620×340，只记一行标题时下半部分是空的。
2. 项目、模块只能用 `↑ ↓` / `Ctrl+↑ ↓` 轮换或点选现有的；只有一个项目、没有模块时什么都切换不了，也没有新建入口，看起来像坏了。
3. 备注和链接只能之后到主窗口补。

## 目标

1. 窗口高度跟着内容变：平时只有「类型 + 标题」一行和底栏；展开详情、打开选择列表时往下长，收起后缩回。顶边位置不动。
2. 标题里按 `Shift+Enter` 展开详情区：Markdown 即时预览编辑器（和主窗口同一个）+ 一行可选的 deeplink。
3. 项目和模块在底栏左侧，点击或 `Ctrl+P` / `Ctrl+M` 在面板里打开可搜索的列表；输入的名字不存在时可以直接新建。
4. 保存后底栏短暂显示「已记到 项目 · 模块」，不再常驻一块列表。
5. 还没有项目时，在小窗里直接输入名字新建第一个项目。

## 不变量

- **记录要快**：呼出后标题输入框立即可输入；编辑器代码延后加载（页面空闲时预取），不影响呼出。
- 小窗不加载视觉效果和主窗口代码（冒烟测试已检查）。
- 输入法选词时的 `Enter` / `Esc` 不触发保存或关闭。
- 关闭小窗时保留未保存的草稿（标题、备注、链接）。

## 按键

| 位置 | 按键 | 作用 |
|---|---|---|
| 标题 | `Enter` | 保存（连同备注和链接） |
| 标题 | `Shift+Enter` | 展开详情并跳到备注 |
| 标题 | `Tab` / `Shift+Tab` | 切换类型 |
| 标题 | `↑ ↓` / `Ctrl+↑ ↓` | 轮换项目 / 模块 |
| 任意 | `Ctrl+P` / `Ctrl+M` | 搜索或新建项目 / 模块 |
| 标题 | `Esc` | 关闭小窗 |
| 备注 | `Ctrl+Enter` | 保存 |
| 备注、链接 | `Esc` | 回到标题（详情为空时收起） |
| 链接 | `Enter` | 保存 |
| 选择列表 | `↑ ↓`、`Enter`、`Esc` | 移动、选中或新建、返回 |

## 实现清单

| 层 | 改动 |
|---|---|
| `internal/store/items.go` | `NewItem` 加可选的 `Note`、`Deeplink`；`CreateItem` 校验后在同一个事务里写入 |
| `internal/store/items_test.go` | 带备注和链接新建；链接不合法、备注过长时不新建 |
| `app.go` | 小窗 `FitContent`，宽度固定 620，最高 640；按固定的参考高度定位，顶边不随高度跳 |
| `src/main.tsx`、`src/index.css` | 小窗的 `html` 标 `data-capture`，取消 `height: 100%`，让窗口按内容测量 |
| `src/capture-app.tsx` | 重写：标题行、详情区（懒加载编辑器）、内嵌选择列表、底栏（选择器 + 提示 / 状态） |
| 文档 | `docs/product.md`、`docs/api.md`、使用说明弹窗的快速记录一节和快捷键表 |

## 验收标准

- 自动：`go vet`、`go test`、`typecheck`、`lint`、`build`、打包后冒烟测试通过。
- 用户在真实窗口里确认：呼出速度；窗口伸缩是否顺滑、顶边是否稳定；Shift+Enter 展开和编辑器渲染；搜索、新建项目和模块；保存后的提示。

## 回滚

只加了两个可选字段，没有改表结构；回滚代码即可，已存的备注和链接照常保留在数据里。
