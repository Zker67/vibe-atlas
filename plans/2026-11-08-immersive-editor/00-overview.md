# 沉浸式编辑器升级，所有编辑器加斜杠命令、查找替换和自动配对

> 状态：`[partial]`：已实现，等用户验收
>
> 来源：用户 2026-11-08 要求沉浸式编辑器「更现代化，具备优点」，认可分析出的建议，同意新增查找替换，并要求斜杠命令在非沉浸式编辑器里也有。

## 目标

### 所有 Markdown 编辑器（详情面板、沉浸式、项目说明、快速记录小窗）

1. **斜杠命令**：在行首或空格后输入 `/` 弹出菜单，继续输入可以筛选（中文名、拼音首字母、英文都行）；`↑ ↓` 选择，`Enter` 或 `Tab` 执行，`Esc` 关闭并留下 `/`。项目：正文、标题 1–3、列表、编号列表、任务、引用、代码块、表格、分隔线、图片（用系统的选择文件窗口，Go 端 `chooseImages` 多选保存）。
2. **查找替换**：`Ctrl+F` 查找，`Ctrl+H` 替换；用官方的 `@codemirror/search`，界面汉化并按应用的样式重画。
3. **自动配对**：输入 `(` `[` `{` `` ` `` `"` 时补上另一半，再输入右半边时跳过；在一对空括号中间退格时两边一起删掉；选中文字后输入这些符号，或 `*` `_` `~`，就把文字包起来。

### 沉浸式编辑（弹窗）

4. **底部状态栏**：字数、行数、约几分钟读完；保存状态（未保存 / 保存中 / 已保存 · 时间 / 保存失败）；右侧是常用快捷键的提示。
5. **铺满窗口**：在「弹窗」和「铺满主窗口」之间切换（按钮或 `F11`），记住选择。
6. **专注模式**：光标所在的段落正常显示，其他段落变淡。
7. **打字机滚动**：光标所在行保持在编辑区中间。
8. **行宽和字号**：窄、中、宽三档行宽；字号可以调大调小。
9. **大纲侧栏**：列出标题，点击跳转，当前所在的章节高亮；可以收起。
10. **折叠标题**：标题左侧的箭头收起或展开这一节。
11. **顶栏**：直接改标题；切换状态（待办 / 进行中 / 完成）和类型；「复制给 AI」；上一条、下一条（`Alt+PageUp / Alt+PageDown`，按队列里看得到的顺序）。`Alt+↑ / ↓` 是编辑器里「上移、下移这一行」，所以没用它。

5–9 的选择存在本机（`localStorage`），下次打开沿用。

## 不变量

- 不内置 AI。
- 弹窗提到主窗口这一层，用全局状态管理，切换上一条、下一条时不关闭；关闭时先等保存完成，再让面板里的编辑器用最新内容重开。
- 斜杠命令、查找替换、自动配对对输入法友好：组字过程中不触发。
- 快速记录的呼出速度不受影响（编辑器本来就是按需加载）。

## 不做（写进 backlog）

- 表格编辑辅助（`Tab` 跳格、自动对齐）。
- 备注的历史版本。
- 只读阅读模式。
