# 全部项目总览与阶段历程

状态：`[partial]`：两个阶段都已实现，检查通过，等用户在真实窗口验收

## 用户原话

> 那总览里面是可以统计信息吗，我觉得是可以的
>
> 两个都做，先做 A，然后要现代化，不要是纯文字，要样式丰富易读

A 是组织级的「全部项目」页，B 是单个项目总览里的阶段历程。都建立在 [2026-11-18-project-stage](../2026-11-18-project-stage/00-overview.md) 之上；A 顺带做掉 backlog 里的「全部项目的总览」。

## 阶段 1（A）：全部项目

主区域新的一页，看当前组织的全部项目。

| 区块 | 内容 |
|---|---|
| 页头 | 图标、「全部项目」、当前组织、项目数；和回收站同一种页头 |
| 阶段分布 | 一条按项目数分段、用阶段色的流水线条；下面五格，每格阶段图标、名称、项目数和「最久 N 天」；点一格只看这个阶段，再点取消 |
| 改进点概况 | 组织里全部改进点的进度环和完成 / 进行中 / 待办；近 28 天每天完成数的柱状图（悬停看日期和条数），旁边是近 7 天完成数和其中有动静的项目数 |
| 项目卡片 | 按阶段分组（完结一组默认收起），每组一个网格；卡片上是项目图标、名称、阶段标签和在这个阶段的天数、进度条和百分比、进行中 / 待办 / 完成三个数、近 14 天完成的小柱状图、最近一次改动的时间。点卡片打开项目的队列，右键有「阶段」「编辑项目」 |

- 入口：侧栏项目列表最上面一行「全部项目」（窄栏里是图标）；选中时底色滑过去。点项目、点模块回到队列；切换组织时留在这一页，换成那个组织的；`Esc` 回到队列。
- 组织还没有项目时，页里显示空状态和「新建项目」。
- 数据：新增 `ProjectActivity(orgID, since)`，返回组织里每个项目最近一次改动的时间和 `since` 以来每条完成的时间；按天分组在前端按本地时间做。只在打开这一页和数据变化时读。

## 阶段 2（B）：阶段历程

- 数据：新表 `project_stages`（项目、阶段、开始时间），迁移时每个项目写入当前阶段一行；新建项目、切换阶段时追加一行，切到当前阶段不追加；删除项目时一起删。
- 项目总览新增「阶段历程」卡片（放在项目说明下面）：一条按时长分段的时间条（每段阶段色，过去的稍淡，当前阶段一直延到现在），下面每一步的阶段、开始日期、用了多久，当前这一步高亮并标「现在」；悬停分段显示起止日期和时长；右上角是从第一步起的日期和总时长。只有一步时也显示。项目说明卡片右上角原来的「开发中 · 已 N 天」和它重复，去掉。
- 只记从升级以后的切换，升级前的历史没有。

## 不变量

- 人工驱动：阶段只由用户切换；统计只读，不改任何数据。
- 记录要快：快速记录小窗不读新数据。
- 视觉：沿用总览的卡片、进度条、进度环和信号色，不另起一套；亮暗两套都能看清；系统要求减少动态效果时不播放动画。
