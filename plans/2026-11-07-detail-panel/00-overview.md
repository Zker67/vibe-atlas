# 详情面板改版：属性区、时间线、轻量的链接和备注

> 状态：`[partial]`：已实现，等用户验收
>
> 来源：用户 2026-11-07 反馈详情面板「太不现代化，底部时间没有样式」，确认全部改进建议都做。

## 目标

1. 时间不再是底部一行用「·」串起来的纯文本，改成属性区里的小时间线：创建 / 开始 / 完成三个节点，节点图标用状态色，时间用 `.meta-mono`，节点之间显示等了多久、用了多久（进行中时实时显示已进行多久），悬停显示完整时间（年月日 + 24 小时制）。
2. 状态、类型、模块不再是三个一样的灰框按钮：
   - 状态改成三段式「待办 | 进行中 | 完成」，直接点选，当前段用状态色填充。
   - 类型的值用和队列一致的彩色 `TypeChip`。
   - 模块带文件夹图标；未分类时显示成淡色的「选择模块」入口。
3. 排版改成两列属性区（左列淡色属性名：状态、类型、模块、链接、时间；右列是值）。
4. 备注平时不画边框，悬停时出现淡底，聚焦时显示描边；上方加带图标的「备注」小标题。
5. 链接没填时只显示淡色的「添加链接」入口，点开才是输入框；填了之后显示成链接卡片（图标 + 域名或文件名，点击打开），编辑和解除放在悬停时出现的按钮里，按钮不挤动内容。
6. 标题加大到 `text-lg`，悬停时出现淡底，提示可以直接编辑。
7. 标题栏按钮：没有其他项目可移时隐藏「移到其他项目」，不再显示一个禁用的图标；「关闭」前加分隔线，和删除分开。删除仍然露在外面，按 `zker67-ui-way`「图标按钮没文字」，删除这类重要按钮不折叠。
8. 详情不再列出子改进点（用户 2026-11-07 追加：「右侧不需要显示子改进点，左侧自己切换就是了」）。右键「添加子改进点」改由队列底部的输入框承接：框前出现「↳ 父改进点标题」标记，Enter 添加为子改进点，`Esc` 或 × 退出。上级路径保留。

## 不变量

- 键盘操作不变：`Space`、`S`、`C`、`O`、`Enter`（`[data-item-title]` 聚焦标题）、`Delete`、`Esc`。
- 标题、链接、备注的保存逻辑不变：标题 Enter 或失焦时保存，Esc 放弃；链接校验失败就地提示且不保存；备注停顿 0.5 秒或失焦时保存。
- 上级路径的行为不变；右键「添加子改进点」仍然可用（改由队列底部输入框承接）。
- 不改后端，不改 `atlas.go`，不需要重新生成 `src/mygo.ts`。
- 亮暗两套主题都只用已有的颜色变量，不硬编码颜色。

## 验收标准

- `bun run typecheck && bun run lint` 通过，`bun run build` 成功。
- 用户在真实窗口里看（亮暗两套）：属性区对齐；时间线节点和耗时正确；状态三段点选生效；未填链接时是入口，填了是卡片，坏链接仍就地报错；备注无边框，悬停和聚焦有反馈。

## 回滚说明
