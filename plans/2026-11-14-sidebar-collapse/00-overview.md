# 侧栏收起成窄栏

## 目标

用户 2026-11-14 提出：「左侧栏应该可以收起缩略」。

1. 侧栏可以在「展开」（240px，现状）和「收起」（56px 的图标窄栏）之间切换。
2. 切换入口：顶栏里的按钮，展开时在侧栏上方的最右边（应用名字那一块里），收起后在窄栏右边，提示分别是「收起侧栏」「展开侧栏」（用户 2026-11-14 调整：原来展开时也在侧栏外侧）；快捷键 `Ctrl+\`（输入时也可以用，和 `Ctrl+,` 一样）。
3. 选择记在本机（`localStorage`），下次打开保持。
4. 窄栏里：
   - 项目、模块、「全部」「未分类」只显示图标，选中的底色照样滑动；有进行中时图标右上角一个小圆点；悬停在右侧提示名称和未完成数量。
   - 「项目」「模块」两段的标题隐藏，只留 `+`。
   - 回收站、使用说明、设置只显示图标，悬停提示名称和快捷键；回收站有条目时图标上标数量。
   - 点图标就是打开项目 / 筛选模块（不再弹图标选择），双击不改名；改名、换图标用右键「编辑」。拖动排序、把队列的条目拖到模块上照常可用，落点只高亮，不显示「移入」徽标。
5. 宽度变化有过渡，系统要求减少动态效果时不播放。

## 不变量

- 展开时的样子和行为不变。
- 不新增依赖；不影响快速记录小窗。

## 实现清单

| 文件 | 内容 |
|---|---|
| `src/state/sidebar.ts` | 收起状态、切换、本机保存 |
| `src/components/app/sidebar.tsx` | 窄栏的行、段标题、底部按钮 |
| `src/components/app/title-bar.tsx` | 左块宽度跟随侧栏，切换按钮 |
| `src/main-app.tsx` | `Ctrl+\` |
| `src/components/app/help-dialog.tsx` | 快捷键表 |
| `smoke_sidebar.go`、`smoke.go` | 冒烟：收起、只剩图标、记在本机、点图标打开项目、展开 |
