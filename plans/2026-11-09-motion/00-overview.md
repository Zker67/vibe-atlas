# 补齐主窗口的动效

> 状态：`[partial]`：已实现，等用户验收
>
> 来源：用户 2026-11-09 说「很多地方忘记加丝滑的 motion 动画了，怎么感觉只有设置切 tab 有」，分析后要求 P1 和 P2 都做。

## 目标

天天用的主窗口操作要有和设置导航同样的丝滑感：

| 优先级 | 地方 | 做法 |
|---|---|---|
| P1 | 所有分段按钮：「队列 / 总览」、状态和类型筛选、详情的状态和类型三段、图标选择器的分类、设置和外观里的单选组、沉浸式编辑的行宽 | 选中的底色滑到新的一段（`Glide`，弹簧曲线），不再跳 |
| P1 | 主区域在队列、总览、回收站之间切换，切换项目 | 内容淡入（`useEntrance`） |
| P1 | 队列改状态后条目换分组 | 行从原来的位置滑到新位置（`useFlip`） |
| P1 | 队列分组和子改进点的折叠、展开 | 下面的行滑动让位，新出现的行淡入（`useFlip`） |
| P2 | 详情面板在空状态、单条、多选之间切换；链接卡片和输入框互换 | 淡入 |
| P2 | 侧栏选中的项目和模块 | 高亮滑过去（`Glide`）；拖动排序时换回各行自己的底色 |
| P2 | 新增的行、`Shift+Enter` 新开的一行 | 淡入（`useFlip` 的进场） |

## 不变量

- **记录要快**：快速记录小窗不加动效；`↑ ↓` 换选中条目时高亮和详情保持立即切换，不淡入。
- 只做进场，不做退场，切换不等动画。
- 系统打开「减少动态效果」时都不播放。
- 不加依赖：用 CSS 过渡和浏览器自带的 Web Animations API。

## 实现清单

| 位置 | 内容 |
|---|---|
| `src/lib/motion.tsx` | `Glide`（测量父元素里选中的那一项，复制它的位置、大小、圆角和 `--chip`，用过渡滑过去）、`useEntrance`（key 变了就淡入）、`useFlip`（行的新旧位置差做位移动画，新行淡入；换项目、换筛选、拖动中不做） |
| `src/components/ui/toggle-group.tsx` | 单选组自带 `Glide`，选中项自己的底色改成透明；`glideClassName` 定制滑块样式 |
| `src/index.css` | `.signal-text`：只给信号色文字，底色交给滑块 |
| `item-detail.tsx`、`icon-picker.tsx`、`project-header.tsx`、`sidebar.tsx` | 接上 `Glide` |
| `main-app.tsx`、`item-detail.tsx` | 接上 `useEntrance`；链接卡片和输入框互换时淡入 |
| `queue.tsx` | 接上 `useFlip`：行、分组标题、新建行带 `data-flip` |

## 验收标准

- `bun run typecheck && bun run lint`、打包后的冒烟测试通过。
- 用户在真实窗口里看：各处分段按钮的滑块、切视图和项目的淡入、改状态时行滑到新分组、折叠展开、详情切换、侧栏高亮；连续按 `↑ ↓` 不卡。

## 回滚说明

去掉 `src/lib/motion.tsx` 的三处接入即可回到硬切；`ToggleGroup` 去掉 `Glide` 后选中项的底色恢复原样。
