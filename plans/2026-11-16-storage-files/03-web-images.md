# 阶段 3：网络图片

> 总览见 [00-overview.md](./00-overview.md)。

## 目标

备注里写成 Markdown 的网络图片 `![](https://…)` 不再只是一行源码：显示成卡片，但不自动联网。

## 规则

- `http:` / `https:` 的图片显示成卡片，排法和本地图片一样（一行只有图片时替换这一行，夹在文字里时显示在这一行下面）。
- 没加载时是占位卡片：地球图标、「网络图片」、图片所在网站的域名，按钮「加载」「保存到本地」。点卡片也是加载。
- 加载过的地址本次运行里一直直接显示（记在内存，重启后重新是占位）。加载失败显示「加载不了这张图片」。
- 「保存到本地」：由 Go 下载（同粘贴网页图片：15 秒、20 MB、PNG / JPG / WebP / GIF / BMP），成功后这一处的地址换成 `image:<文件名>`，可以撤销；失败提示原因。
- 右键菜单：加载图片（没加载时）、保存到本地、在浏览器中打开、复制图片地址、删除图片。
- 复制给 AI 时网络图片保留原地址。
- 粘贴网页内容时的下载行为不变；粘贴 Markdown 文本时不下载。

## 验收标准

- 写 `![](https://…)` 后离开这一行：显示占位卡片，没有网络请求。
- 点「加载」显示图片；点「保存到本地」后源码变成 `image:`。
