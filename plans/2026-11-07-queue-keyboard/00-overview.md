# 队列键盘操作：Tab 改层级、Enter 行内改名、Shift+Enter 连续新建同级；拖到侧栏模块改模块

> 状态：`[partial]`：已实现，等用户验收
>
> 来源：用户 2026-11-07 明确提出（不在第一期原计划里，由用户直接要求加入）。

## 目标

1. 选中队列里的改进点时，`Tab` 把它变成上面最近一条同级改进点的子改进点（缩进一层），`Shift+Tab` 把它移到上一级（取消缩进）。
2. 选中后按 `Enter`（或 `E`），在中间队列的这一行里直接改名，和双击一样；`Enter` 确认，`Esc` 放弃。
3. 行内改名时按 `Shift+Enter`：保存这一条，在它下面新开一行同级改进点直接起名；起好名再按 `Shift+Enter` 继续往下加。
4. 把队列里的改进点拖到侧栏的模块（或「未分类」）上，改成那个模块。
5. 父改进点标为完成时，下面所有没完成的子改进点一起完成（用户 2026-11-07 提出）；已完成的父改进点撤回未完成时，下面已完成的子改进点一起退回待办（用户 2026-11-07 追加）。实现上所有改状态的入口和拖动都按 `src/state/atlas.ts` 的 `statusPlan` 决定哪些条目跟着变、变成什么。

## 不变量

- 不改 Go 接口和数据结构：只用现有的 `CreateItem` 和 `MoveItem`（`before` / `after` / `inside`）。
- 数据库里不出现空标题的改进点：新开的那一行只是输入框，有标题后才真正新建。
- 焦点在按钮等控件上时，`Tab` 仍然按浏览器习惯移动焦点；输入框里的 `Tab` 不受影响（队列底部输入框仍是切换类型）。
- 快速记录小窗不受影响。

## 规则（写入 `docs/product.md`）

- `Tab`：在同一个分区里，往上找最近一条同一层的改进点，成为它的最后一条子改进点（它收起着会自动展开）；上面没有同一层的就不动。
- `Shift+Tab`：只对子改进点有效，移到上一级，放在原来上级的后面（同右键「移到上一级」）；它后面的同级不跟着动。
- `Enter` / `E`：队列里显示着这一条时在行内改名；在总览页或这一条被筛掉、收起时，仍然在详情里编辑标题。
- `Shift+Enter` 新建的一条：和上一条同一个上级、同类型、同模块，状态是待办，排在上一条（连同它的子改进点）后面。`Enter` 或点别处保存；空着按 `Esc` 或点别处就不加；保存失败时提示错误，输入框保留。
- 上一条是顶层的进行中或已完成时，新建的是待办，会出现在「待办」分区，后续 `Shift+Enter` 跟着它继续。
- 拖到侧栏模块：拖的这一条和它下面所有子改进点一起改成那个模块（用户 2026-11-07 确认；右键「移到模块」仍只改这一条）；都已经在这个模块里时不算落点。「全部」不是落点；「未分类」只在侧栏显示时能拖上去。

## 实现清单

- `src/components/app/queue.tsx`：`renameInQueue`、`indentItem`、`outdentItem`；`RowTitleInput` 支持 `Shift+Enter`；新增 `DraftRow`（新一行的输入框），渲染在上一条的子树后面。
- `src/main-app.tsx`：快捷键里接 `Tab` / `Shift+Tab`，`Enter` / `E` 优先行内改名。
- `src/components/app/help-dialog.tsx`：使用说明和快捷键列表。
- 拖到模块：`queue.tsx` 的落点多一种 `module`（侧栏行带 `data-module-drop`），`sidebar.tsx` 的模块行和「未分类」行用 `useModuleDropOver` 高亮。
