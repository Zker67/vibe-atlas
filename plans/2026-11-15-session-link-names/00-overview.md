# 按链接来源显示会话名

状态：`[partial]`：已实现并通过自动检查，等用户在真实窗口验收

## 目标与范围

「会话来源」仅决定选择会话列表。粘贴或已有的 Codex、Claude Code、codeg 链接按自身来源读取名称，包括设置为「不使用」时。仅查询本批链接涉及的来源；一个来源失败不影响其他来源。保留只读、本地、异步查询和短 ID 兜底，不修改用户设置或数据。

## 实施与验证

1. 名称查询按链接来源分组，列表缓存按来源保存，选择列表仍用设置的来源。
2. 补充跨来源、失败隔离、无关来源不读取及缓存的回归测试；同步接口和产品说明。
3. 运行 Go 检查和测试、生成绑定、前端类型检查和 lint。

用户验收：保持 codeg 来源，粘贴 Codex 链接，保存后显示实际会话名；选择会话列表仍显示 codeg。

## 回滚

还原本次源码和生成绑定即可；无数据库迁移。

## 实施结果

- 名称查询按链接来源分组，失败隔离，列表缓存按来源独立保存；选择列表仍按设置读取。前端无需因选择来源变化重新查名，设置说明和接口文档已同步。
- `CGO_ENABLED=0 go vet ./...`、`CGO_ENABLED=0 go test ./...`、新增入口定向测试、`bun run generate`、`bun run typecheck`、`bun run lint`、`git diff --check` 均通过。
- 使用用户提供的 Codex 链接调用修改后的读取器，只读验证成功取得本机会话名。
- 修复纳入 0.6.3，发布入口为 [GitHub Release](https://github.com/Zker67/vibe-atlas/releases/tag/v0.6.3)；真实窗口交互由用户验收。
