# 备注粘贴图文混排的内容

> 状态：`[partial]`：已实现，等用户验收
>
> 来源：用户 2026-11-08 反馈「备注应该能通过粘贴的方式，粘贴内容进去，包括图片，但是目前好像没做好」。

## 现状

- 只粘贴一张图片（截图、浏览器「复制图片」、资源管理器里复制的图片文件）：有处理，但冒烟测试只测了保存图片，没测粘贴这一步。
- 粘贴图文混排的内容（网页、Word、飞书等）：剪贴板里有文字时只取纯文本，图片全部丢掉，格式也没了。

## 目标

1. 粘贴的 HTML 里有图片时，转成 Markdown 插入：标题、粗体、斜体、删除线、行内代码、代码块、链接、列表（可嵌套）、引用、分隔线、表格；图片保存到本地，留在原来的位置，写成 `![](image:<name>)`。
2. 图片来源：
   - `data:` 内嵌图片：直接保存。
   - `http(s)` 网络图片：由 Go 下载后保存（15 秒超时，不超过 20 MB）；下载失败时保留原链接 `![](原地址)`。
   - `file:` 本机文件（如 Word 复制时的临时图片）：由 Go 读取后保存。
   - 剪贴板里正好一张图片文件、HTML 里正好一张图时，直接用图片文件的内容。
   - 有图片没能保存时提示条数。
3. HTML 里没有图片时，照旧按纯文本粘贴（从代码编辑器复制的内容也带 HTML，不能转换）。
4. 只有图片、没有文字时，照旧把图片单独放一行。
5. 保存图片超过一小会儿时，显示「正在保存粘贴的图片」。

## 不变量

- 转换用浏览器自带的 `DOMParser`，解析出的文档是惰性的，不执行脚本、不加载图片；不新增依赖。
- `javascript:` 等非 http(s)/mailto/file 的链接不保留为链接，只留文字。
- 保存期间用户继续打字时，内容插到当前光标处（和拖入图片一致）。

## 实现清单

| 文件 | 改动 |
|---|---|
| `images.go` | `SaveImageFrom(src)`：下载网络图片或读取本机图片文件后保存 |
| `images_test.go` | 用本地 HTTP 服务和临时文件测试：成功、404、不是图片、超过大小、不支持的地址 |
| `src/components/editor/paste-html.ts` | HTML 转 Markdown，图片换成占位符并列出来源 |
| `src/components/editor/images.ts` | 粘贴时有图片的 HTML 走转换，保存图片后一次插入 |
| `smoke_images.go` | 在真实窗口里模拟粘贴：单独一张图片、一段图文混排的 HTML |
| `src/mygo.ts` | `bun run generate` 重新生成 |
| `docs/product.md`、`docs/api.md`、`src/components/app/help-dialog.tsx` | 说明同步 |

## 验收标准

- `go vet`、`go test`、`typecheck`、`lint` 通过；打包后冒烟测试通过。
- 真实窗口里：从网页复制一段带图片的内容粘贴进备注，文字格式和图片都在；截图直接粘贴照常成为图片；从 VS Code 复制代码仍是纯文本。
